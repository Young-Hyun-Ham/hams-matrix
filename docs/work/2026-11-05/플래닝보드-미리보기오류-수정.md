# 플래닝보드 미리보기 오류 수정

- 작성일: 2026-11-05 (한국시간)

## 주요 변경사항

- 헤더 `미리보기` 버튼은 `onPreview`를 통해 편집기의 새 창 열기와 데이터 전송을 호출하고 있었다. 해당 버튼의 기존 배치는 유지했다.
- 기존 페이지 썸네일 선택 버튼 내부에 multi select의 × 버튼이 들어가는 중첩 버튼 구조를 제거했다. 썸네일과 페이지 선택 버튼을 형제 요소로 분리하고, 버튼의 클릭 영역은 카드 전체를 덮도록 했다.
- 썸네일 내용에는 `inert`, `aria-hidden`을 적용하여 내부 입력 컨트롤이 키보드 포커스나 접근성 트리에 노출되지 않도록 했다. 본문 미리보기의 컨트롤은 유지한다.
- 활성 페이지·hover·포커스 및 다크 스타일을 새 카드 구조에 맞췄다.
- 새 창의 준비 메시지를 기다리는 제한 시간을 5초에서 60초로 늘려 개발 모드 초기 컴파일이 늦어져도 저장 전 편집 내용을 전달할 수 있도록 했다. 기존 origin·창 객체·nonce 검증은 유지했다.
