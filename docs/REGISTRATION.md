# 가입 역할, 플랜과 팀 승인

## 가입 흐름

- owner: 가입 화면에서 역할을 선택하면 플랜 모달이 열립니다. Team(99,000원: 5명 사용 기준, 월 500개 화면 생성, 공유·협업·버전 관리) 또는 Business(별도 견적: 조직별 사용량 협의, 표준 템플릿 적용, 보안·관리 기능)를 반드시 선택합니다.
- user: Guest 또는 팀을 선택합니다. Guest는 Free(0원) 조회 전용 계정입니다. 팀을 선택하면 신청을 저장하며 owner 승인 전까지 Guest 공간만 접근할 수 있습니다.
- 결제·요금 청구·사용량 제한은 적용하지 않습니다. 요금표의 제공 항목은 플랜 선택 안내이며 해당 기능의 구현 여부와는 별개입니다.
- Google/Naver/Kakao 신규 가입은 인증 직후 `/onboarding`에서 같은 선택을 완료합니다. 미완료 계정은 업무 API와 워크스페이스에 접근할 수 없습니다. 기존 소셜 계정 로그인에는 이 단계를 반복하지 않습니다.

팀은 `workspaces`로 관리합니다. 신규 owner의 팀 이름은 `이름의 팀`이며, `subscription_plan`이 team/business인 팀만 가입 검색에 표시합니다. 팀 검색은 회원가입 전에도 가능하며 팀 ID와 이름만 최대 30개 반환합니다. 기존 계정·프로젝트·플랜은 보존하며 기존 Free owner를 자동으로 유료 플랜으로 변경하지 않습니다.

## 승인과 권한

owner는 **팀 공유 → 팀 가입 신청**에서 승인·거절할 수 있습니다. 본인 팀의 owner만 처리할 수 있고 처리 완료된 신청은 다시 승인하지 못합니다. 신청 목록은 승인 대기 건을 우선해 최대 100개 표시합니다.

승인 시 member 워크스페이스 멤버십과 기존 프로젝트 참여 관계를 생성하고, 신청자의 현재 워크스페이스와 로그인 세션을 승인된 팀으로 전환합니다. 신청자는 화면을 새로고침하거나 다시 로그인하면 반영됩니다. 승인된 user는 이후 생성된 프로젝트에도 자동 포함됩니다. 거절된 신청자는 Guest로 남습니다. Free 사용자를 owner가 직접 추가하는 경로는 viewer를 부여합니다. 상세 운영은 [팀 공유와 프로젝트 권한](TEAM_COLLABORATION.md)을 참고하세요.

`users.account_role`은 가입 유형 owner/user이고 `workspace_members.role`은 팀 소속 권한입니다. Free Guest의 기본 권한은 viewer이며 팀 가입 승인 후에는 member가 됩니다. user 계정도 member/admin으로 승인·지정되면 역할에 따른 변경 작업을 할 수 있습니다. 프로젝트별 권한과 단일 소유자는 별도로 관리합니다. 가입 시 입력하는 담당 역할·직무는 `users.job_title`이며 접근 권한과 구분합니다. UI와 서버에서 동일한 역할 검사를 적용합니다.

## 저장 및 이력

`004_registration_teams.sql`은 계정 역할·온보딩 완료 여부·현재 워크스페이스, 워크스페이스 소유자·플랜, `team_join_requests`를 추가합니다. 기존 `workspaces.plan`의 제약과 호환하려고 Team은 기존 컬럼에 pro로, 새 `subscription_plan`에는 team으로 저장합니다. 서비스의 플랜 표시는 새 컬럼을 우선합니다.

가입, 팀 신청, 승인·거절과 공유 권한 변경은 감사 이력과 같은 트랜잭션으로 저장합니다. `DB_LOGGING_ENABLED` DB 설정이 true일 때만 이력을 추가합니다. 승인 이력 저장이 실패하면 멤버십·프로젝트 공유·세션 전환도 모두 롤백됩니다.

`scripts/migrate.mjs`는 `schema_migrations`에 적용 파일을 기록합니다. 새 SQL은 파일을 추가해 적용하며 이미 적용한 파일을 수정해서 재실행하지 않습니다. 기존 001~003은 최초 이력 등록 시 한 번 재실행해도 데이터를 유지하는 SQL입니다.

`pnpm test:auth`는 별도 테스트 DB에서 플랜 필수 선택, Guest, 승인 전 격리, 승인·거절, 기존·신규 프로젝트 공유, 권한 우회 차단, 승인 이력 실패 시 롤백과 소셜 온보딩 게이트를 검증합니다.
