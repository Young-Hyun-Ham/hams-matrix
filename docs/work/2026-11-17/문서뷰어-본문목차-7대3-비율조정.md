# 문서 뷰어 본문·목차 7:3 비율 조정

- 작성일: 2026-11-17 (한국시간)
- 요청: 이전 목차 40단위 폭 확장을 취소하고 본문(content):목차 비율을 7:3으로 변경한다.
- 상태: 구현 및 관련 검증 완료.
- 후속 변경: 메뉴를 접을 때 목차까지 늘어나지 않도록, 7:3은 메뉴 펼침 상태의 기준으로 조정했다. 현재 동작은 [본문 단독 확장 기록](문서뷰어-메뉴접기-본문단독확장.md)을 따른다. 아래 내용은 당시 구현·검증 이력이다.

## 주요 변경사항

- 읽기 영역의 padding과 열 간격을 제외한 가용 공간을 `minmax(0, 7fr) minmax(0, 3fr)`로 나눈다.
- 한글·영문 가중 길이 계산, canvas 글꼴 폭 측정, 목차 고정 폭 변수와 글꼴 로딩 후 재측정을 제거했다. 제목 길이가 목차 폭을 늘리지 않는다.
- 긴 제목은 한 줄 말줄임·전체 제목 안내를 유지한다. 숨김 스크롤과 독립 휠 이동, 목차 높이 제한, Mermaid 동작은 유지한다.
- 70% 본문 열에 최소 500px을 확보하지 못하면 목차를 숨기고 본문을 1열로 표시한다. 목차가 없거나 원문 모드일 때도 기존 1열을 유지한다.
- 메뉴 접기 시 두 열이 7:3으로 함께 늘어나므로 같은 목차 표시 상태에서 본문 증가량은 확보된 가용 폭의 70%다.

## 변경 파일

- `app/(workspace)/viewer/md/MarkdownViewer.tsx`: 문자 폭 측정 제거, 70% 본문 최소 폭 기준으로 목차 표시 판단.
- `styles/pages/viewer/md/MarkdownViewer.module.css`: 본문:목차 grid를 7:3으로 변경.
- `scripts/test-viewer.mjs`: 문자 수별 폭 보장 대신 실제 7:3 비율, 긴 제목 말줄임, 메뉴 전환 시 본문 증가량을 검증.
- `README.md`, `AGENTS.md`, `CLAUDE.md`: 현재 레이아웃 정책 갱신.
- `WORK_HISTORY.md`, 이전 작업 기록: 새 작업 링크와 기존 정책의 대체 사실 추가. 기존 다른 변경은 보존한다.

## 검증

- 변경 파일 ESLint 및 `pnpm typecheck` 통과.
- 합성 문서/임시 SQLite 기반 뷰어 브라우저 회귀 통과. 메뉴 펼침·접힘과 여러 화면 폭에서 본문:목차의 실제 폭이 7:3인지 검증했다. 긴 제목이 목차를 넓히지 않고 말줄임되는 것과 본문 증가량도 확인했다.
- 목차 행 높이·독립 휠·숨김 스크롤, 중첩 컨테이너 폭 대응, 목차 없는 문서 1열, Mermaid 여섯 종류·오류·테마·키보드 전환, 기존 문서 검색·탭·초안·스타일 격리 회귀도 통과했다.
- 브라우저 회귀는 최신 소스를 읽는 격리 개발 서버(`node scripts/test-viewer.mjs --dev`)에서 수행한다.
