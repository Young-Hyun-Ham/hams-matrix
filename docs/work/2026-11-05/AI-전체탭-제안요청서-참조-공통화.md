# AI 전체 탭 제안요청서 참조 공통화

- 작성일: 2026-11-05 (한국시간, Asia/Seoul)
- 상태: 구현 및 관련 검증 완료.

## 주요 변경사항

- `lib/ai/page-prompts.ts`에 `rfpReferenceInstructions` 공통 변수를 추가했다. 제안요청서 출처·조회 방법·전체 장 구조·문서 부재와 권한 오류 구분·출처 표기·중복 및 추측 방지·권한 범위 등을 한 곳에서 관리한다.
- `pageInstructions()`에서 공통 지침을 모든 페이지 시스템 프롬프트에 한 번 주입한다. 기존 WBS·요구사항·DB의 중복 지침을 정리하고, 각 탭에는 제안요청서를 해당 업무에 활용하는 방법을 남겼다.
- WBS·아키텍처·요구사항·화면·DB·프로그램·검증·개요·추적·검수·변경 이력·내보내기 등 모든 일반 프로젝트 탭에 `document_json` 전체와 실제 ID/version을 제공한다. 초기 `pageContext.rfp`와 도구 응답 `data.rfp`가 같은 조회 경로를 사용한다.
- 제안요청서 탭 자체의 기존 `document.draft` 조회·저장 형식은 유지하고 공통 지침에 별도 접근 경로를 명시했다.
- 변경 이력 탭의 제안요청서는 현재 저장본임을 명시해 과거 이력의 증거로 오인하지 않도록 했다. 조회 전용 탭의 저장 권한은 추가하지 않았다.
- 대시보드·팀 공유에는 특정 프로젝트 문서를 임의 제공하지 않고, 프로젝트와 작업 탭을 선택하도록 안내한다.

## 변경 파일

- `lib/ai/page-prompts.ts`: 공통 프롬프트 변수·주입 및 모든 페이지의 역할별 안내.
- `lib/ai/page-data.ts`: 일반 프로젝트 탭의 전체 RFP 전달 통일, 변경 이력 응답 포함.
- `scripts/check-wbs-rfp-context.mjs`: 전체 탭·공통 지침·권한·기존 DB 등록 회귀 검증 확장.
- 본 문서, `WORK_HISTORY.md`: 작업 기록 및 상대 경로 링크 추가.

## DB 변경 여부

실제 DB·스키마·마이그레이션 변경 없음. 기존 `readRfp()`의 프로젝트·워크스페이스·권한 검사와 삭제 문서 제외를 유지한다. 검증은 임시 SQLite와 합성 데이터만 사용했다.
