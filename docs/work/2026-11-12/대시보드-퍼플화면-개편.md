# 대시보드 퍼플 화면 개편

- 작성일: 2026-11-12 (Asia/Seoul)
- 기준: [최신 설계](../../history/2026-11-12/대시보드-퍼플화면-개편-설계.md)를 다시 읽고 권장안을 구현함.
- 상태: 구현·관련 검증 완료. 기존 사용자 변경과 설계 문서를 보존했다.

## 주요 변경사항

- 문서 작업 흐름 배너, 전체/개별 URL 필터, 요약 4종, 프로젝트 카드, 최근 산출물, 재검증 후보, 최근 활동, 하단 설계 작업 동선을 구현했다.
- 전용 요약 GET·최소 DTO·읽기 트랜잭션을 추가했다. workspace/배정·READ·이력 플랜을 적용하며 원본 snapshot/fields/structure는 응답하지 않는다.
- SSR와 클라이언트 Query key를 일치시키고 생성·산출물 CRUD·AI 변경 후 대시보드 무효화를 연결했다. 기존 개인 테마와 guest 서버 접근 제한을 유지한다.
- 최근 변경은 KST 오늘 포함 7일 UPDATE 횟수, 진행률은 요구사항 완료율, 영향 미리보기는 승인된 통과 검증의 baseline 버전 불일치로 구현했다.
- README.md, AGENTS.md, CLAUDE.md, 화면/CSS 안내와 WORK_HISTORY.md를 갱신했다.

## 변경 파일

- 신규: `app/api/dashboard/route.ts`, `lib/dashboard-types.ts`, `lib/dashboard-model.ts`, `lib/dashboard-query.ts`

## DB 변경 여부

운영 DB·스키마·마이그레이션 변경 없음. 기존 테이블을 조회한다. 테스트만 임시 SQLite에 기존 마이그레이션과 합성 계정을 적용한다. 운영 자격증명이나 실제 AI 요청을 테스트에 사용하지 않는다.

## 검증 결과

- `pnpm test:dashboard`: 통과. 실제 route/auth와 임시 SQLite로 배정·workspace 격리, 삭제 제외, READ 축소, 빈 상태, 이력 플랜, 배정 해제, KST 7일/자정 경계, 반복 UPDATE, baseline 누락/삭제/불일치를 검증했다. 현재 READ는 고정 허용이므로 제한 분기는 실제 권한 함수의 반환값을 축소하는 테스트 어댑터로 추가 검증했다.
- `pnpm typecheck`: 통과. sandbox의 설치 패키지 읽기 제한을 피한 재실행 기준이다.
- `pnpm test:query-audit`: 통과. 호출 164개 중 미분류 0건.
- 전체 lint: 기존 `scripts/test-wbs-view.mjs`의 규칙 오류 2건으로 실패. 기존 경고 8건. 이 작업에서 해당 파일을 수정하지 않았다.
- 변경 TS/TSX/MJS 파일만 설치된 ESLint로 검사: 통과. `pnpm exec`의 Windows spawn 오류를 피하기 위해 `node node_modules/eslint/bin/eslint.js ...`로 실행했다.
- `pnpm build`: 통과. 최종 SQL·모달 포커스 수정 포함, TypeScript 검사 및 64개 정적 페이지 생성 완료. 정적 생성 중 일반 `Request failed Error` 로그가 출력되었으나 빌드 종료 코드는 0이었다.
- `pnpm test:dashboard-browser`: 통과. production Next와 headless Chrome, 별도 임시 SQLite에서 SSR·필터·뒤로 가기·새로고침, RFP 프로젝트 선택·Escape/포커스 복귀, 실제 탭 링크, 네트워크 오류/복구, 미배정 ID, viewer/빈 프로젝트, 생성 후 RFP 이동과 단일 생성, POST 405·HEAD·OPTIONS를 확인했다. 브라우저 런타임 예외 0건.
- 1440/1024/768/390px에서 페이지 전체 가로 넘침 없음. 라이트/다크·모바일 및 실제 빈 AI 대화방 생성 후 패널 확대 상태를 확인했다. AI 메시지는 전송하지 않았다. 캡처는 로컬 `.auth-tests/dashboard/desktop-dark.png`, `desktop-light.png`, `mobile-dark.png`, `desktop-ai-expanded.png`에 있으며 데스크톱/모바일 캡처를 직접 확인했다.
- 작업 전후 파일 해시 비교에서 변경된 기존 파일은 이 작업의 대상 파일에 한정되었고 기존 파일의 추가 삭제는 없었다. 전체 diff 검사에서 나온 `PROMPT.md` 공백 경고는 기존 내용으로 수정하지 않았다.

## 제한·미완료 사항

- 이번 구현 범위의 미완료 사항 없음. 전체 lint의 기존 오류 2건은 남아 있다.
- 설계 권장안대로 특정 산출물의 자동 상세 선택, 별도 AI 생성 마법사, 파일/RFP까지 포함하는 통합 문서 목록, 전체 변경 전파 탐지는 추가하지 않았다. 최근 산출물은 실제 종류의 탭으로 이동하고 영향 카드는 확인 가능한 재검증 후보만 표시한다.
- 기존 서버 `requireUser()`/프로젝트 권한은 guest의 프로젝트 접근을 금지한다. 신규 API도 이를 유지하며 guest용 서버 읽기 권한을 새로 부여하지 않았다.
