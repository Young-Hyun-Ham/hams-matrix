# 플래닝보드 템플릿 생성 팝업 닫힘 수정

- 작성일: 2026-11-05 (한국시간)
- 증상: 템플릿 생성 메뉴를 클릭해도 팝업이 표시되지 않는 것처럼 보임.

## 주요 변경사항

- 템플릿 생성 모달의 효과 정리 함수에서 실행하던 `dialog.close()`를 제거했다. 개발 모드의 React Strict Mode 효과 재실행 시 `close` 이벤트가 부모의 닫기 처리를 실행할 수 있었다.
- 닫힌 상태에서만 `showModal()`을 실행한다. 실제 DOM 제거 시 브라우저가 모달을 해제하므로 정리 함수의 `close()`는 필요하지 않다.
- 기존 닫기·취소·ESC, 생성 중 취소 제한, 이름 입력·생성·오류 처리를 유지했다.
- 기존 개발 서버를 보존하고 소스 복사본·별도 Chrome 프로필·임시 DB에서 개발 모드 팝업 회귀 검증을 실행하는 옵션을 추가했다.

## 사용 방법

1. 프로젝트 master 계정으로 해당 프로젝트의 플래닝보드를 연다.
2. 템플릿으로 보관할 캔버스를 편집한다.
3. 좌측 페이지 영역의 `… → 템플릿 생성`을 선택한다.
4. 팝업에서 이름을 입력하고 `생성`을 누른다.
5. 같은 프로젝트의 템플릿 목록에서 생성한 템플릿을 사용할 수 있다. 다른 프로젝트에는 표시되지 않으며 원본 설계서 저장과는 별개다.
