# 스타일 작업 위치

페이지 전용 CSS는 `components/pages/<메뉴>/<메뉴>-page.css`에서 관리합니다. 여러 화면에서 사용하는 스타일은 다음 파일에서 수정합니다.

| 파일                  | 담당 영역                                       |
| --------------------- | ----------------------------------------------- |
| `workspace.css`       | 공통 CSS 진입점과 불러오기 순서                 |
| `workspace-shell.css` | 사이드바, 상단 헤더, 탐색, 본문 배치            |
| `shared-ui.css`       | 패널, 안내 문구, 아이콘 버튼, 상태 표시, 아바타 |
| `page-heading.css`    | 페이지 제목과 상단 작업 버튼 배치               |
| `table.css`           | 프로젝트 필터, 검색, 탭, 표, 페이지 이동        |
| `dialog.css`          | 공통 다이얼로그, 계정 설정, 도움말, 상세 보기   |
| `accessibility.css`   | 모션 감소 설정 대응                             |
| `themes.css`          | 라이트·다크 테마                                |
| `auth.css`            | 로그인·회원가입 화면                            |

전체 색상·간격 토큰과 기본 버튼은 `app/globals.css`에서 관리합니다.

`app/(workspace)/layout.tsx`는 `workspace.css`를 불러옵니다. 공통 파일의 import 순서는 이 진입점에서 유지하며, 페이지가 개별 공통 파일을 중복해서 불러오지 않습니다. 각 영역의 반응형 규칙은 해당 영역의 CSS 파일에 함께 둡니다. 페이지에만 필요한 선택자는 페이지 전용 파일에 추가합니다.

공통 스타일이나 import 순서를 바꾼 뒤에는 영향을 받는 메뉴의 데스크톱·모바일 화면과 라이트·다크 테마를 확인하고 `pnpm build`로 프로덕션 CSS 처리를 검증합니다.
