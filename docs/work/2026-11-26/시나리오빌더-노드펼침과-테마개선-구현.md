# 시나리오 빌더 노드 펼침과 테마 개선 구현

작업일 2026-11-26 (KST)

## 변경 내용

- 독립 일반 노드는 접힘과 펼침 모두 250px를 사용한다. Group 자식의 너비 정책을 유지하고 본문 줄바꿈, Form 미리보기 스크롤, iFrame 미리보기 폭을 정리했다.
- Sub Agent의 접기·펼치기 버튼을 헤더 첫 요소로 옮겼다. 캔버스는 자식 크기와 상대 위치에서 부모 영역을 계산하며 접힌 조상의 자손과 그 연결선을 화면에서 숨긴다. 크기 계산은 표시용으로 적용한다.
- 가져오기는 선택 시점의 배포 버전 번호를 확인한 뒤 기존 버전 API에서 스냅샷을 읽는다. 중첩 부모와 연결 ID를 재매핑하고 탭 전환 후 응답을 버린다. 가져온 사본은 자동 갱신하지 않으며 속성 패널 재선택은 기존 제목·참조 설정 동작을 사용한다.
- Add Node 모달과 조건형·버튼형 Branch 본문에 빌더 테마 변수를 적용했다.

## 변경 파일

- 빌더 노드 `NodeWrapper.jsx`, `ScenarioNode.tsx`, `BranchNode.jsx`, `IframeNode.jsx`, `ChatNodes.module.css`

DB 변경 없음. 기존 시나리오 상세·버전 조회 계약을 사용한다.

## 검증 결과 및 남은 사항

- `node scripts/test-scenario-canvas.mjs` 통과. 중첩 영역, 자식 크기 변경, 레거시 접힘, 연결선 표시를 확인했다.
- `node scripts/test-builder.mjs` 격리 DB 검사 31개 통과.
- 전체 TypeScript 검사 `tsc --noEmit --incremental false` 통과. 기본 실행의 의존성 접근 오류는 승인 경로에서 해결됐다.
- 승인 경로의 `node scripts/test-builder-browser.mjs`에서 일반 노드의 토글 전후 너비와 다크 Add Node 검색 입력의 테마 검사가 통과했다. 이후 기존 시뮬레이터 단계는 `.builder-emulator`를 기다리다 중단됐다. 현재 시뮬레이터는 챗봇 호스트의 서버 실행 패널을 사용하므로, 전체 브라우저 회귀를 재개할 때는 기존 시뮬레이터 선택자와 초기화 검사를 현재 UI 계약에 맞춰야 한다.
- Sub Agent의 실제 드롭·배포판 선택과 Branch의 라이트·다크 시각 검증은 남아 있다. Sub Agent의 영역과 접힘 모델은 위 단위 검증으로 확인했다.
