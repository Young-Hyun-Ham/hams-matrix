# ERD 캔버스 반응형 최대 3열 배치

- 작성일: 2026-11-09 (한국시간, Asia/Seoul)
- 요청: ERD · 테이블 관계 화면에서 창 크기에 따라 한 행에 최대 3개 테이블 표시.

## 주요 변경사항

- 고정 2열·850px 캔버스를 실제 표시 영역 너비에 따른 1~3열 배치로 변경했다.
- `ResizeObserver`로 캔버스 컨테이너를 관찰하므로 창 크기와 표시 영역 변경에 바로 대응한다.
- 카드 폭 330px과 관계선 공간은 유지한다. 필요한 캔버스 폭은 1열 420px, 2열 850px, 3열 1280px이며 실제 테이블 개수보다 많은 열을 만들지 않는다. 더 좁은 화면에서는 내부 가로 스크롤을 제공한다.
- 열 수에 맞춰 행 높이·카드 위치·전체 캔버스 크기·FK 연결 좌표를 함께 다시 계산한다. 기존 수정·삭제 및 FK 삭제 제한은 유지한다.

## 변경 파일

- `components/pages/database/database-diagram.tsx`: 너비 관찰과 동적 열 수·좌표 계산.
