# WBS 계획공수 근무일 자동 계산

작성일: 2026-11-16 (한국시간)

## 주요 변경사항
- WBS 등록·수정 모달에서 계획 시작일·종료일 변경 시 양 끝 날짜를 포함한 월~금 근무일 × 하루 8시간으로 계획공수를 자동 입력한다.
- 현재 별도 근무일·공휴일 달력 설정이 없어 토·일만 제외한다. 공휴일은 제외하지 않는다.
- 상위 작업·선행 작업 관계 선택으로 계획일이 자동 조정될 때도 재계산한다.
- 마일스톤 계획공수는 0시간이다. 날짜 누락·잘못된 날짜·역전 기간은 계산값을 비우며 기존 날짜 검증을 유지한다.
- 실제공수가 비어 있으면 0으로 초기화한다. 수정 모달에서 기존 실제공수와 기존 계획공수는 열기만 해서는 변경하지 않는다. 계획공수는 날짜·작업유형 변경 시 갱신하며 수동 수정도 가능하다.
- 공통 모달 스타일 및 기존 다른 변경사항을 유지한다.

## 변경 파일
- components/pages/wbs/wbs-form-state.tsx: 초기값 및 날짜 변경·관계 조정 후 공수 계산 연결.
- lib/wbs-effort.ts: 시간대에 영향받지 않는 근무일 공수 계산.
- scripts/test-wbs-effort.mjs: 단일 평일, 주말, 여러 주, 연도 경계, 윤년, 잘못된 기간, 마일스톤 및 실제공수 보존 검증.
- README.md, AGENTS.md, CLAUDE.md, WORK_HISTORY.md: 작업 기록 링크 추가.

## DB 변경 여부
- 스키마·기존 데이터 변경 없음. 모달 저장 시 기존 저장 경로를 사용한다.

## 검증 결과
- node scripts/test-wbs-effort.mjs: 통과.
- node node_modules/typescript/bin/tsc --noEmit: 통과.
- 변경 파일 ESLint: 통과.
- 브라우저 수동 확인은 수행하지 않았다. 확인 방법: 평일 하루는 8, 월~금은 40, 금~월은 16, 주말만 선택 시 0시간인지 확인하고 실제공수 0 초기값 및 수정 시 기존 값 보존을 확인한다.
