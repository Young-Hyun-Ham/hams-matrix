# 제안요청서 요구사항 목록 높이 및 스크롤 조정

- 작성일: 2026-11-03 (한국시간)

## 주요 변경사항

- 세부 요구사항의 좌측 목록 높이를 우측 요구사항 상세 영역과 동일하게 맞췄다.
- 목록에 크기 격리를 적용하여 항목 수가 많아도 전체 행 높이가 늘어나지 않도록 하고 `overflow-y: auto`로 내부 세로 스크롤을 제공한다.
- 상세 입력 영역 높이가 변경되면 CSS Grid 배치에 따라 목록 높이도 함께 변경된다. 상세가 없는 빈 목록에는 크기 격리를 적용하지 않는다.
- 620px 이하의 기존 세로 배치에서는 목록 최대 높이를 320px로 제한하고 내부 스크롤을 유지한다.

## 검증 결과

- 실제 CSS를 임시 HTML에 적용한 Chrome 렌더링 검증 통과.
- 80개 목록 항목에서 우측 상세와 좌측 목록의 높이가 600px로 일치하고, 상세 높이를 800px로 변경한 뒤에도 일치함을 확인했다.
- 목록의 실제 콘텐츠 높이가 표시 높이보다 크고 `overflow-y`가 `auto`인 것을 확인했다.
- 모바일 미디어 쿼리에서 목록 높이 320px 제한과 내부 세로 스크롤을 확인했다.
