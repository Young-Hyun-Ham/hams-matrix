# 플래닝보드 미리보기 페이지·영역 캡처

- 작성일: 2026-11-05 (한국시간)

## 주요 변경사항

- 미리보기 상단 닫기 버튼 옆에 페이지 캡처와 영역 선택 캡처 아이콘을 추가했다. 각 버튼에 한글 툴팁과 접근성 이름을 제공한다.
- 페이지 캡처는 현재 본문 페이지 DOM만 PNG로 다운로드한다. 상단 바·썸네일·페이지 바깥 배경은 포함하지 않는다.
- 영역 캡처는 현재 페이지 위에서 드래그로 지정하며 역방향 드래그와 페이지 경계 제한을 지원한다. 축소된 미리보기 좌표를 페이지 원본 픽셀 좌표로 환산하여 잘라낸다.
- ESC·취소 버튼으로 영역 선택만 취소하고 미리보기 창은 유지한다. 너무 작은 드래그와 포인터 취소는 다운로드하지 않는다. 창 크기나 페이지 표시 배율이 바뀌면 진행 중인 선택을 취소하여 좌표가 어긋나지 않도록 했다.
- 캡처·선택 중 페이지 전환 및 중복 실행을 차단한다. 오류가 나면 안내를 표시하고 버튼을 다시 사용할 수 있게 한다.
- 기존 `html-to-image` 의존성을 클릭 시 동적으로 로드하며 폰트 준비를 기다리고 기존 비공개 이미지 요청에 같은 출처 인증을 사용한다. 별도 패키지 설치나 API는 추가하지 않았다.
- 파일명에 페이지 이름·page/region 구분·타임스탬프를 사용한다. 과도한 캔버스 메모리 사용을 막기 위해 한 변 16,384px 또는 전체 16,777,216픽셀 초과 시 안내한다.
