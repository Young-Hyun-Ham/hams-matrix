# 챗봇 우측 시나리오 실행 패널 및 / 커맨드 구현

작성일 2026-11-26 (한국시간)

## 주요 변경사항

- 일반 채팅 옆에 시나리오 패널을 배치했다. 화살표는 표시만 전환하고, 좁은 화면에서는 채팅과 실행을 한 화면씩 표시한다. 시나리오 실행은 우측 패널에서 명시적으로 시작하며, 기존 실행·입력·이력 경로를 재사용한다.
- 빌더 상세 모달의 버전 조회 버튼 왼쪽에 커맨드 등록 토글을 추가했다. 전용 PATCH로 현재 관리자 권한과 revision을 검사하고 등록 상태를 저장한다.
- `/`에는 같은 워크스페이스에서 ON으로 등록한 배포 시나리오가 표시된다. 커맨드에서 선택하면 우측 패널에 미리 선택되며, 이미지·문서 생성은 `☰`에서 사용한다. 커맨드 목록은 기존 일반 배포 목록과 별도 조회하며 일반 배포 목록의 100건 제한을 적용하지 않는다.

## 변경 파일

- 챗봇 호스트·입력·시나리오 화면·런타임과 `styles/chatbot.css`
- 빌더 시나리오 목록·타입·Turso 서비스·저장소, View 시뮬레이터 버튼 문구, 커맨드 상태 PATCH 및 챗봇 시나리오 목록 GET
- `db/migrations/056_builder_scenario_command.sql`, 빌더 및 챗봇 검증 스크립트, README·AGENTS·CLAUDE·WORK_HISTORY

## DB 변경

`056_builder_scenario_command.sql`만 구성 Turso DB에 적용했다. `builder_scenarios.command_enabled`는 기본값 0과 0/1 검사 제약을 사용한다. 적용 이력, 컬럼 기본값과 외래키 위반 0건을 실제 DB에서 읽기 전용으로 확인했다.

## 검증과 미완료 사항

- TypeScript 검사 통과. 임시 DB와 모의 공급자를 사용한 챗봇 통합 검증 178건, 빌더 API·저장소 검증 30건 통과.
- 변경 대상의 `git diff --check`와 브라우저 스크립트 구문 검사 통과.
- 변경된 챗봇 소스와 API 경로의 ESLint 검사 통과. Chrome 전체 검증에서 `/` 목록, 실행, 패널 숨김·복원, 이미지·문서 생성 및 Flow 자동 실행을 확인했다. 이후 View 버튼의 깨진 문구를 수정하고 빌더 구간을 별도로 재실행해 Flow/View 자동 시작, 폼과 모바일 등 11건을 통과했다.
- 팝업을 유지하는 동안 방을 전환해도 현재 실행을 보존한다. 새로고침이나 다른 탭에서 활성 run을 복원하는 동작은 후속 범위다.
