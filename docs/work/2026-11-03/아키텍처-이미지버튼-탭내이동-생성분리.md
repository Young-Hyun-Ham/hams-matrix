# 아키텍처 이미지 버튼 탭 내 이동 및 생성 분리

- 작성일: 2026-11-03 (한국시간)

## 주요 변경사항

- 구성도 상단에 있던 미리보기·PNG 다운로드 버튼을 ‘아키텍처 구성도’ 탭 내부의 선택된 아키텍처 명칭 오른쪽으로 이동했다.
- 버튼 순서를 ‘AI 이미지생성 → 미리보기 → PNG 이미지 다운로드’로 구성했다.
- 생성/재생성 모달은 AI 이미지생성 버튼으로만 연다. 미리보기·다운로드에서 이미지가 없다고 생성 모달로 전환하지 않으며 미리보기 모달의 다시 생성 버튼도 아키텍처에서는 표시하지 않는다.
- 저장 이미지 조회 결과와 선택된 아키텍처 ID·버전을 기준으로 미리보기·다운로드 활성 여부를 판단한다. 이미지가 없거나 조회 중/실패하면 비활성화한다. 새 생성 완료 후에는 최신 조회 결과로 활성화한다.
- 생성 모달 취소는 바로 닫기로 처리한다. 기존 이미지와 Mermaid 미저장 편집 보호, 생성 권한 검사는 유지한다.
- 공통 이미지 컴포넌트에 아키텍처 전용 옵션을 추가하여 WBS 등 다른 화면의 기존 생성 진입 동작은 유지한다.
- 좁은 화면에서는 명칭과 버튼을 줄바꿈하여 표시한다.

## 변경 파일

- `components/pages/architecture/architecture-diagram.tsx`: 탭 내부 명칭 옆 버튼 배치 및 이미지 존재 여부 관리.
- `components/pages/architecture/architecture-image-actions.tsx`: 아키텍처 전용 생성 분리 옵션 전달.
- `components/pages/architecture/architecture-image-surface.tsx`: 저장 이미지 조회 결과 전달.
- `components/pages/architecture/architecture-page.css`: 명칭/버튼 행 배치.
- `components/shared/ai-image-actions.tsx`: 명시적 생성 버튼, 저장 이미지 조건부 활성화 및 조회/생성 모달 분리.
- `scripts/test-architecture-surface-browser.mjs`: 버튼 위치와 활성화, 생성 진입·취소 및 조회 모달 검증 보강.
- `components/pages/architecture/README.md`, `WORK_HISTORY.md`: 동작 및 작업 기록 갱신.
