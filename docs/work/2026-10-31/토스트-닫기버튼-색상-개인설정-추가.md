# 토스트 닫기 버튼 색상 개인 설정 추가

- 작업일: 2026-10-31 (한국시간)

## 주요 변경사항

- 설정 → 인터페이스 관리 → 토스트 탭에 `토스트 닫기 버튼 색상`, `토스트 닫기 버튼 바탕색` 선택기를 추가했다.
- 다른 개인 설정과 같은 미리보기·저장·취소·계정 격리 흐름을 사용한다. 토스트/기본 테마를 부분 저장해도 두 색상은 보존한다.
- `닫기 버튼 기본색 복원`은 두 값을 NULL로 되돌린다. 미지정/기존 사용자는 버튼 글자가 토스트 본문 색상을 따르고 배경은 시스템 ButtonFace를 사용하여 기존 기본 동작을 유지한다.
- 실제 토스트 닫기 버튼에 개인별 색상을 적용하고 기존 닫기 동작은 유지했다.

## DB 변경

- user_preferences에 nullable HEX 컬럼 `toast_close_button_color`, `toast_close_button_background_color`를 추가했다. 각 컬럼은 NULL 또는 정확한 6자리 HEX만 허용한다.
- 실제 DB에서 미적용·동명 컬럼 부재를 확인한 뒤 028만 트랜잭션으로 적용하고 schema_migrations에 기록했다. 두 컬럼 존재를 확인했다.
- 기존 다른 설정값과 업무 데이터를 변경하지 않았으며 기존 023 이력 불일치에는 손대지 않았다.
