# 작업 기록 — 회원·권한·요금제 개편

2026-10-28, 구현 및 검증 완료. 기준 문서: [HISTORY.md](../../../HISTORY.md).

- 기존 변경 파일은 유지하며 별도 작업 중이다.
- 020 마이그레이션과 회원 플랜/사용량 예약 서버 모듈을 추가하고 실제 DB에 적용했다.
- 일반 가입 user/Free, 현재 보유 프로젝트 수, AI 실행 회원 과금, 산출물 이력은 owner 플랜 기준으로 구현한다.
- 연간 가격은 미정(NULL)으로 유지한다. 총 토큰은 갱신 규칙 확정 전 자동 리셋하지 않는다.
- 가입 user/Free, 로그인 회원등록·게스트 버튼, 관리자 플랜/회원 설정, 비로그인 데모, 프로젝트 권한, 워크스페이스 전환을 반영했다.
- AI 토큰·이미지 예약/정산, 동적 첨부 한도, Free 임시 대화와 산출물 이력 미생성을 연결했다.
- 실제 DB: 020·021 적용, master 생성·지정 비밀번호 해시 검증 성공. 기존 user 1명 보존. app_settings 원문 동일, foreign_key_check 통과. 재실행 시 master 비밀번호를 덮어쓰지 않는 것도 검증했다.
- 검증: 최종 프로덕션 빌드(타입 검사 포함), 회원·플랜 HTTP 테스트, 한도 동시성·최종 정산 테스트, 기존 아키텍처·WBS 이미지 회귀 테스트 통과.
- 인증·산출물·팀 협업 전체 회귀 검사와 AI 전체 검사(이미지/CRUD/대화/토큰/취소/가드레일/첨부 문서) 통과.
- 반복 AI 검사 중 로컬 SQLite 동시 조회의 SQLITE_BUSY가 발생해 테스트 DB WAL 모드 및 로컬 연결 busy timeout을 적용했다. 관리자 가드레일 테스트의 첨부 수도 회원 플랜 기준으로 통일했다.
- 최종 사용량 미확정 시 예약 유지·응답 중복 차감 방지·기존 사용량 이관 테스트 통과. 일회성 편집 스크립트 4개 삭제 완료.
- ESLint 오류 0건. 기존 integration-overview.tsx의 미사용 report 경고 1건은 기존 변경을 보존하기 위해 유지했다.
- 주요 경로: /admin/plans(플랜·회원 관리), /settings/subscription(내 플랜·사용량), /guest/dashboard(비로그인 샘플 체험).
- 유료 플랜은 관리자가 계약·입금 확인 후 수동 부여한다. 자동 결제·Business 청구서 발행은 미연결이며, 미정 연간 가격과 토큰 갱신 정책은 임의 확정하지 않았다.
- 소스·DB 변경 요청 범위를 완료했으며 토큰 만료로 중단된 작업은 없다.
