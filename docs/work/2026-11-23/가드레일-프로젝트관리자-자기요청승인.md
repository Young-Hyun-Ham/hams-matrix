# 가드레일 프로젝트 관리자 자기 요청 승인

- 작성일: 2026-11-23 (한국시간)
- 요구사항: 컨트롤타워에서 해당 프로젝트 관리자 권한이 있으면 자기 요청도 승인 처리한다.

## 주요 변경사항

- 기존 자기 요청 일괄 차단을 수정했다. 기존 컨트롤타워 관리 범위 권한에 더해 요청 프로젝트의 owner 또는 admin이면 자기 요청의 승인·반려를 허용한다.
- 현재 프로젝트·workspace 소속과 역할을 상세/목록의 버튼 활성 조건 및 처리 트랜잭션에서 동일하게 확인한다. 프로젝트 없음/member/viewer는 자기 처리를 차단한다.
- 필수 의견·승인 확인·버전 충돌·정책/원본 재검증·이력 기록·사용자 명시적 재개는 유지한다.
- 이전 구현 기록의 자기 승인 금지 방침은 이 후속 사용자 요구사항으로 대체한다.

## 변경 파일

- `lib/ai/guardrail-approvals.ts`: 프로젝트 관리 역할 조회 및 자기 처리 허용 조건.
- `components/admin/guardrail-approval-detail.tsx`: 자기 처리 제한 안내 수정.
- `scripts/test-ai-guardrail-approvals.mjs`: 자기 요청 owner/admin 허용, 프로젝트 없음/member 차단, 실제 승인·재개·처리자 이력 회귀.
- `README.md`, `AGENTS.md`, `CLAUDE.md`, `docs/AI_GUARDRAILS.md`, `WORK_HISTORY.md`, 본 기록: 운영 기준·변경 이력 갱신.

## DB 변경 여부

없음. 기존 프로젝트/멤버·승인/이력 테이블을 사용하며 구성 DB를 수정하지 않았다.

## 검증 결과

- 임시 SQLite·합성 계정·모의 AI를 사용하는 `node scripts/test-ai-guardrail-approvals.mjs` 통과. 기존 전체 승인·재개 회귀와 새 자기 처리 권한 검증을 함께 수행했다.
- 변경 파일 ESLint 직접 실행 통과. `pnpm exec eslint`는 환경의 실행 래퍼 EPERM으로 시작하지 못해 Node로 ESLint 진입점을 직접 실행했다.
- `pnpm typecheck` 및 `git diff --check` 통과.
- 브라우저 재검증은 수행하지 않았다.

## 미완료 사항

구현 미완료 사항 없음. 컨트롤타워 자체 접근 권한은 기존 상품/workspace 관리자 범위를 유지한다.
