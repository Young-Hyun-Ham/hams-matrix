# 제안요청서 AI 생성 요청 범위 프롬프트 추가

- 작업일: 2026-11-03 (한국시간)

## 주요 변경사항

- AI 생성 확인 모달에 선택 입력인 **생성 요청 범위 · 추가 프롬프트**를 추가했다. 최대 2,000자, 글자 수 표시, 예시와 빈 입력 안내를 제공한다. 취소 후 모달을 다시 열어도 같은 화면에서는 입력을 유지한다.
- 프롬프트를 생성 API와 AI 입력의 `requestScope`로 전달한다. 장·주제·상세도·요약 요청에 맞게 작성하고, 지정 범위 밖 항목은 빈 값/빈 목록으로 두도록 지시했다. 빈 입력은 기존처럼 원본 전체를 대상으로 한다.
- 기존 저장본 전체 교체 안내는 유지한다. 범위 밖 항목이 비어 있을 수 있음을 모달에서 알린다. 특정 장만 기존 문서에 병합하는 기능은 추가하지 않았다.
- 서버에서 프롬프트 타입·길이를 검증한다. 요청 범위가 달라지면 같은 요청 ID를 재사용할 수 없으며, 공백 제거 후 빈 입력은 이전 프롬프트 없는 요청과 같은 식별 규칙을 사용한다.
- 기존 권한·중지·문서 검증·버전 충돌 검사는 유지했다. 사용자가 비활성화한 내용 가드레일 호출은 변경하지 않았다.
- 파일 전체를 읽는 방식과 기존 출력 토큰·시간 한도는 그대로다. 프롬프트는 생성 범위를 제한하며 파일 자체를 물리적으로 분할하지 않는다.

## DB 변경 여부

- 스키마·마이그레이션 변경 없음. 프롬프트는 기존 생성 요청 테이블의 `input_json`에 기록한다. 이번 검증에서 연결 DB의 데이터는 변경하지 않았다.
