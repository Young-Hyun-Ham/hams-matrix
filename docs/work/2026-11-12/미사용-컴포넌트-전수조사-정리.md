- 작성일: 2026-11-12 (한국시간, Asia/Seoul)
- 기준: 사용자 구현 요청 후 [설계 문서](../../history/2026-11-12/미사용-컴포넌트-전수조사-정리-설계.md)의 최신 본문·판정표·결정 사항을 다시 읽고 권장안 범위를 적용했다.
- 상태: 구현 완료. 검증 통과와 기존 실패·제한을 아래에 구분한다.

## 주요 변경사항

- 삭제 전 참조를 다시 조사하여 D01~D18과 동반 정리 4개에 삭제 대상 묶음 밖 소비자가 없음을 확인했다.
- 미사용 컴포넌트·훅·유틸리티 18개, 전용 CSS 2개, 샘플 데이터·프로젝트 store 2개 등 총 **22개 파일**을 삭제했다.
- 재조사 결과 컴포넌트 디렉터리 코드는 158개에서 **140개**, CSS는 50개에서 **48개(공통 17개·화면 31개)**다. 남은 컴포넌트 관련 소스는 모두 진입점에 연결되고 해석되지 않은 로컬 import와 미연결 JSX는 없다.
- 현재 14개 프로젝트 탭·가입/온보딩·상품 관리자·플래닝보드·동적 아이콘·공통 CSS·공개 API와 서버 의존성을 유지했다. 테스트가 직접 호출하는 lib/admin-history.ts도 유지했다.
- WBS 안내를 현재 간트·공개본 진입점에 맞게 정정했다. 현재 노출되지 않는 AI 이미지 버튼은 복원하지 않고 WBS 이미지 API 계약은 보존했다.
- README.md·AGENTS.md·CLAUDE.md와 스타일 안내를 갱신했다. 과거 설계·작업 기록·기존 이력 항목은 보존했다.

### 통과하지 못한 검증

- test-architecture-mermaid.mjs, test-architecture-images.mjs: fixture의 workspace Free와 사용자 Business 불일치로 WORKSPACE_PLAN_MISMATCH. 각각 201/이미지 없음 기대 대신 409/불일치 응답을 받았다.
- test-wbs-view.mjs: 맞춤 TypeScript 로더가 일반 TS의 제네릭을 JSX로 해석하여 SyntaxError가 발생했다.
- test-wbs-form-browser.mjs: fixture bundler가 @tanstack/query-core를 해석하지 못했다.
- 위 **4개는 삭제한 22개 파일을 원본 해시와 일치하게 복원한 별도 임시 소스 복제본에서도 같은 실패를 재현**했다. 삭제로 인한 신규 회귀로 분류하지 않았다. 실제 저장소에는 복원하지 않았다.
- test-auth.mjs: check-projects.mjs:31에서 팀 회원 목록 응답 200 기대와 실제 409가 불일치했다. 전체 인증 회귀 통과로 기록하지 않는다. 이 HTTP 시나리오는 삭제 전 별도 빌드로 재현하지 않았으며, 관련 API·fixture 파일은 변경하지 않았다.

## 미완료 사항·재개 정보

- 요청한 소스 정리와 안내·작업 기록 갱신의 구현 미완료 사항은 없다.
- 전체 린트 및 위 fixture·인증 통합 검증 실패는 별도 개선 대상으로 남긴다. 재개 시 최신 설계와 본 기록을 읽고 fixture의 사용자/workspace 플랜·맞춤 TS/bundler 해석·인증 검증의 409 응답 조건을 먼저 확인한다. 개인 설정 테마 검증에는 간헐성이 남아 있다.
- 직접 브라우저 검증이 프로젝트 14개 탭의 모든 업무 동작, 실제 OAuth 제공자·유료 AI·외부 문서 편집기까지 보장하지 않는다.
- lib/admin-history.ts 폐기·과거 테스트 계약 전환·미사용 CSS 선택자·의존성 정리·WBS AI 버튼 재연결은 설계대로 이번 범위에서 제외했다. 권한이나 서버 정책을 완화하여 실패한 테스트를 통과시키지 않았다.
