# 화면설계서 목록 완료 플래닝보드 미리보기

- 작성일: 2026-11-05 (한국시간)

## 주요 변경사항

- 프로젝트 화면설계서 목록의 플래닝보드 열에 미리보기 버튼을 추가했다. 기존 편집기 실행 버튼은 유지한다.
- 실제 `planning_boards.status`가 `complete`인 화면설계서만 링크를 활성화한다. 초안·검토 중·반려·미작성 항목은 비활성 버튼과 안내를 표시한다. 일반 화면설계서 상태와 플래닝보드 검토 완료 상태가 별개이므로 보드 상태를 기준으로 한다.
- 프로젝트 데이터 조회에 같은 프로젝트·워크스페이스의 보드 상태를 한 번에 조회하여 `Artifact.planningBoardStatus`로 제공한다. 개별 행마다 별도 API 요청을 하지 않으며 저장 구조나 기존 이력에는 이 표시용 값을 추가하지 않는다.
- 활성 링크는 프로젝트·화면 ID를 포함한 기존 `/planning-board/preview`를 새 창으로 열며 `noopener noreferrer`를 적용한다. 동일한 페이지 이동·표시·페이지/영역 PNG 캡처 기능을 사용한다.
- 목록은 완료된 저장본을 미리보므로 nonce를 붙이지 않는다. 편집기 헤더의 미리보기는 기존처럼 nonce와 `postMessage`로 미저장 편집 상태를 전달한다.
- 기존 BroadcastChannel 목록 갱신을 재사용하여 완료·재저장 상태 변경을 반영한다. 완료 후 편집·저장으로 초안이 되면 다시 비활성화된다.
