# 커스텀 테마 라이트·다크 버튼 분리

- 작성일: 2026-11-11 (한국시간)
- 요구사항: 라이트/다크 프리셋 옆에 커스텀 버튼을 각각 배치.

## 주요 변경사항

- 테마 선택을 2행×4열로 변경: 각 행에 주황·파랑·초록 프리셋과 해당 밝기의 커스텀 버튼을 나란히 표시한다.
- 라이트 커스텀/다크 커스텀 선택 시 해당 밝기로 미리보기하고 색상 편집을 허용한다. 프리셋 색상 잠금은 유지한다.
- 저장된 `themePreset=custom`과 `defaultTheme` 조합으로 선택 버튼을 복원한다. 커스텀 색상은 밝기를 전환해도 보존한다. 기존 저장 형식과 헤더 전환·취소·토스트 기능을 유지한다.
- 키보드 상하 이동도 4열 기준으로 맞췄다.

## 변경 파일

- `components/interface-settings.tsx`
- `styles/settings.css`
- `scripts/test-personal-preferences-browser.mjs`
- README.md, AGENTS.md, CLAUDE.md, WORK_HISTORY.md와 본 기록.
