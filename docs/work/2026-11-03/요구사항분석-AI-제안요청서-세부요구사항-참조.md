# 요구사항 분석 AI 제안요청서 세부 요구사항 참조

- 작성일: 2026-11-03 (한국시간)

## 주요 변경사항

- 요구사항 분석 챗봇의 최초 문맥과 `read_page` 재조회에 같은 프로젝트의 저장된 제안요청서 세부 요구사항을 추가했다.
- `rfp`에 문서 ID·버전·제목과 `requirements` 전체(원본 ID·번호·분류·제목·정의·상세내용·산출물·검수 기준)를 제공한다.
- 기존 `readRfp`를 사용하여 제안요청서 READ 권한 및 프로젝트·워크스페이스·삭제 여부를 검사한다. 미저장 편집본이나 원본 첨부 파일은 읽지 않는다.
- 기존 산출물 건수 `total`과 제안요청서 존재 여부 `rfpAvailable`을 구분하여 산출물이 0건이어도 세부 요구사항을 근거로 작성하도록 안내했다.
- 원본 번호는 출처로 사용하며 신규 산출물의 ID·관리번호로 재사용하지 않도록 했다. 원본에 없는 조건은 확인 필요로 구분하고 기존 산출물을 조회하여 중복 등록을 피하도록 안내했다.
- 제안요청서 없음과 세부 요구사항 목록이 비어 있는 경우를 구분한다. 기존 명시적 등록 요청·저장 권한·가드레일 규칙은 유지한다.
- WBS는 기존 수행 및 관리 참조를 유지하며, 그 외 탭에는 제안요청서를 추가하지 않는다.

## 변경 파일

- `lib/ai/page-data.ts`: 요구사항 탭의 제안요청서 참조 및 탭별 전달 범위.
- `lib/ai/page-prompts.ts`: 세부 요구사항 중심 작성 지침.
- `scripts/check-wbs-rfp-context.mjs`: 요구사항 조회·최신 도구 응답·빈 목록·격리 검증 추가.
- `WORK_HISTORY.md`: 작업 기록 링크 추가.
