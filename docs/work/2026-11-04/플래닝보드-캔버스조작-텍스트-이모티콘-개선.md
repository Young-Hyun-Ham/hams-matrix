## 주요 변경사항

- 캔버스 포커스 상태의 방향키 1px 이동, 키 반복/드래그의 작업 단위 Undo/Redo, 한 페이지 영역 다중 선택·Shift 추가·트리 선택 동기화와 공통 이동을 연결했다.
- 상·하·좌·우 한 축 및 모서리 크기 조절, 선택 요소 중앙 이동, 마우스 위치 기준 우클릭 대상과 권한·잠금 확인을 적용했다.
- 텍스트 개행/공백, 가로·세로 정렬 6개 버튼, 배경색/투명, 미리보기와 코드 내보내기 보존을 반영했다. 마크업 한 줄 복사는 콘텐츠 손실을 막기 위해 제한한다.
- 메모 옆 이모티콘 패널과 번호/표정/손동작/기호/업무 탭을 추가했다. 번호 1~30은 빨간 원형 배경·흰 숫자의 기존 text 요소로 저장한다.
- 기존 변경으로 템플릿 항목이 `screens-template2`로 바뀌어 예전 브라우저 검증이 실패하던 것을 확인했다. 현재 템플릿과 문서 JSON 형식을 유지하면서 불러오기와 검증을 연결했다.
