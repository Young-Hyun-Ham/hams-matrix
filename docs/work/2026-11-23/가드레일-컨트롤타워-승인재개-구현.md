# 가드레일 컨트롤타워 승인·재개 구현

- 작업일: 2026-11-23 (한국시간)
- 기준: 최신 `docs/history/2026-11-23/Guardrail_Control_Tower_화면설계.md`와 연계 설계를 다시 읽고 구현했다.
- 상태: 구현·구성 DB 적용 및 브라우저 승인/재개 검증 완료.
- 기존 HISTORY.md·PROMPT.md 및 설계 문서의 사용자 변경을 보존했다.

## 주요 변경 및 범위

1. 관리자설정의 가드레일 탭에 **컨트롤타워 이동**과 팝업 차단 시 보조 링크를 추가했다. 선택 workspace를 유지한 독립 창을 열고 기존 정책 초안은 유지한다.
2. 컨트롤타워의 승인 대기/승인 후 재개 대기/처리 이력, 전체 범위 요약, KST 날짜·요청자·프로젝트·규칙·검사 단계·상태 필터와 cursor 페이지를 구현했다. 요청 직접 링크도 지원한다.
3. 요청 선택 시 오른쪽 상세에서 사용자 작업 요청·마스킹된 차단 근거·승인 후 작업 범위·처리 이력을 확인한다. 의견 입력 및 승인 범위 확인 후 승인/반려하며 자기 승인·다른 상품/workspace 접근·중복 처리를 차단한다.
4. AI 챗봇에 정책명과 예/아니요, 대기 카드, 이어서 진행/취소, 상태 복원·새로고침·종료 카드 닫기를 연결했다. 예 선택 전에는 관리자 목록에 표시하지 않고, 관리자 승인만으로 실행하지 않는다.
5. 완료한 모델 응답·조회 결과·pending 변경안과 검사 카운터를 암호화 journal에 보관하고 복원한다. 같은 논리 요청의 같은 검사 객체에만 승인 예외를 적용하며 다른 단계/내용의 차단은 새 승인을 요구한다. 기존 사용자 변경안 HITL과 최종 원자 저장을 유지한다.
6. 재개 선점 시뿐 아니라 실제 실행 진입 및 최종 저장 트랜잭션에서도 현재 정책·권한·원본/참조·대상 scope를 대조한다. 동시 재개는 한 건만 선점하고 만료·취소·실행 lease 종료를 처리한다.

적용 범위는 이력 저장이 가능한 Team/Business 챗봇이다. 표시 정책명은 규칙명+정책 버전이며, 현재 관리자 권한 체계를 재사용한다. 요청/승인 의견은 필수, 자기 승인은 금지한다. 선택 전 30분, 전송 후 24시간 유효하며 승인으로 만료를 연장하지 않는다. 서버 비밀정보·민감정보·위험한 마크업·필수 검사 실패·권한·실행 한도는 예외 승인 대상이 아니다.

실제 재개는 **기존 foreground POST의 누적 실행 기한 내 처리**로 구현했다. 승인 대기 중 HTTP/모델/생성 lease/트랜잭션을 유지하지 않으며 별도 무기한 실행 worker는 추가하지 않았다. 문서의 후보 저장소는 승인/challenge/checkpoint/attempt 메타데이터를 승인 테이블과 기존 생성 요청에 결합하고 감사 이벤트를 분리하는 2개 신규 테이블로 구체화했다.

## DB 변경

- **변경 있음 / 구성 DB 적용 완료.** `051_ai_guardrail_approvals.sql`만 선택 적용했다. 선행 050을 검사하며 관련 없는 미적용 migration은 적용하지 않는다.
- 기존 `ai_generation_requests`의 ID·데이터·인덱스를 보존하면서 `paused` 상태를 추가했다. 승인·암호화 checkpoint·단일 활성 요청 제약과 별도 append-only 처리 이력 테이블을 추가했다.
- 읽기 전용 검증: 051 적용 기록 확인, 신규 테이블 2개, 필수 열 확인, 외래키 위반 **0건**, checkpoint 암호화 설정 정상. 키 값이나 접속 정보는 출력/기록하지 않았다.
- 완료·반려·취소·만료 시 checkpoint를 제거한다. 조회 시 만료/끊긴 실행을 정리하고 미접속 요청은 `pnpm cleanup:guardrail-approvals`로 주기 정리할 수 있다.

## 남은 작업 및 재개 정보

- 요청한 컨트롤타워·챗봇 승인/재개 범위의 미구현 항목은 없다. 재검증은 `pnpm test:ai-guardrail-approvals-browser`로 실행한다. 외부 AI 호출은 테스트 서버 preloader에서 차단한다.
- 별도 확장 범위: 헤더 승인 알림, 관리자 원문/첨부 열람, 일괄 승인, 독립 이미지·Mermaid/RFP/일괄 생성/RAG 경로의 승인 adapter 또는 비활성 검사 복구. 이번 화면/챗봇 범위의 동작을 임의로 다른 경로에 적용하지 않았다.
- 미접속 만료 요청의 정기 물리 정리가 필요하면 운영 스케줄에 정리 명령을 연결한다. 기존 암호화 키를 교체하기 전 대기 요청을 처리/종료해야 한다.
- 기존 전체 회귀 fixture/샘플 Query 감사 실패는 별도 유지보수 대상으로 남긴다. 테스트 성공을 위해 기존 업무 제약을 완화하지 않았다.
