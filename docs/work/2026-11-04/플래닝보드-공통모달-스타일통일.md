# 플래닝보드 공통 모달 스타일 통일

- 작성일: 2026-11-04 (한국시간)
- 요청 범위: 이력, 설계서 저장, 검토 요청, 설계서 완료 모달에 Matrix 공통 모달 스타일 적용.

## 주요 변경사항

- 저장·검토 요청·완료 모달의 별도 중첩 모달을 제거하고 공통 `workspace-form-dialog` 헤더·본문·하단 버튼 구조를 적용했다. 같은 컴포넌트를 사용하는 반려 모달에도 동일하게 적용된다.
- 공통 모달 너비, 글꼴, 여백, 그림자, 본문 스크롤, 닫기·취소·확인 버튼 스타일을 재사용한다.
- 이력 모달의 개별 너비를 제거하고 공통 닫기 버튼과 공통 탭 스타일 및 현재 탭 표시를 적용했다.
- 플래닝보드의 일반 버튼·다크 스타일이 해당 공통 모달의 버튼 색상을 덮어쓰지 않도록 적용 범위를 조정했다. 개인 강조색도 공통 버튼 규칙을 따른다.
- 검토자 선택 UI에 맞춰 안내와 라벨을 정리하고 깨진 선택 안내 문구를 수정했다.
- 처리 중 버튼 비활성화, ESC 취소 제한, 기존 저장·검토 처리와 이력 조회 로직을 유지했다.
