# 헤더 알림 카드 분리·확인 처리

작성일: 2026-11-16 (한국시간)

## 주요 변경사항

- 일반 헤더 알림을 제목·상태·내용·이동 링크가 구분된 그림자 카드로 표시한다. 개인 테마 색상, 모바일 폭, 패널 스크롤을 적용한다. 계약 알림 목록에도 같은 카드 스타일을 적용한다.
- 일반 알림 카드의 본문 또는 링크 클릭 시 서버에 확인 상태를 저장하고 서버가 계산한 정확한 미확인 수로 배지를 갱신한다. 같은 카드를 여러 번 클릭하거나 다시 열어도 중복 차감하지 않는다. 본문 버튼은 키보드로 확인할 수 있다.
- 사용자+현재 workspace 범위로 확인 상태를 격리한다. 다른 사용자/확인 불가능한 알림 키는 서버에서 거절하며 Origin 검사·저장 재시도 금지를 유지한다.
- 카운터 15초 조회와 상세 패널 열 때 조회를 유지한다. 카운터 API에는 이름·목록을 넣지 않는다.

## 알림이 사라지는 조건

| 종류 | 카드 확인 시 | 목록에서 사라지는 조건 |
| --- | --- | --- |
| AI 토큰 한도 초과 | ‘확인함’ 표시, 배지 1건 감소 | 현재 workspace의 내 실제 누적 사용량이 설정 한도 이하가 됨 |
| 팀 가입 신청 | ‘확인함’ 표시, 해당 사용자 배지 1건 감소 | 신청이 승인 또는 거절되어 pending이 아님 |
| Business 계약 신청 | 기존 read_at 저장·미확인 수 재조회·신청 화면 이동 유지 | 계약 신청 상태가 approved 또는 rejected |

AI 토큰은 월별 자동 초기화가 없는 누적 기준이다. 시간이 지났다는 이유만으로 카드가 없어지지 않는다. 한도를 누적 사용량 이상으로 올리면 AI 카드가 사라진다. 확인 후 같은 한도를 계속 초과하거나 사용량이 늘어도 다시 미확인으로 만들지 않는다. 한도 값을 변경하면 확인 상태를 초기화하여 새 기준의 초과를 알린다. HITL만 변경하거나 같은 한도를 저장하면 확인을 유지한다. 사용량 정정으로 한도 이하가 된 뒤 같은 한도를 재초과하더라도 기존 확인은 유지한다. 팀 재신청은 ID와 신청 시각을 합쳐 새 알림으로 구분한다.

목록은 다음 패널 조회 때 최신 조건을 반영하며, 카운터는 최대 약 15초 내 재조회한다. 확인 클릭 응답은 즉시 카드를 갱신한다. 확인은 업무 신청의 승인·거절이 아니다. 처리 후 확인 행은 DB에 남지만 목록과 카운터에서 제외된다(별도 기간 삭제 없음).
