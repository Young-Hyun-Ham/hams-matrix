# 개인 설정 인터페이스·테마 색상 및 토스트 하위 탭 개편 구현

- 작업일: 2026-10-31 (한국시간)
- 기준: [최신 설계 문서](../../history/2026-10-31/개인설정-인터페이스-테마색-토스트탭-개편.md)를 다시 읽고 권장안을 적용했다. 중단된 요청에서 이번 기능에 반영된 변경은 없었으며 기존 작업 변경사항은 보존했다.

## 주요 변경사항

- 인터페이스 관리에 `인터페이스`/`토스트` 하위 탭을 추가했다. 로컬 탭 상태·키보드 좌우/Home/End 이동을 사용하며 두 탭의 초안을 공유한다. 저장 시 변경한 옵션만 함께 전송하고 취소 시 저장값을 복구한다.
- 인터페이스에는 기본 라이트/다크 모드, 강조색 선택기·HEX 입력, 기본색 복원과 적용 예시를 제공한다. 토스트 위치·배경색·폰트색·미리보기는 토스트 탭으로 이동했다.
- 강조색은 로그인 사용자별 HEX 값 또는 NULL(사이트 기본 보라색)로 저장한다. NULL이면 기존 모드별 primary/primary-soft를 정확히 유지한다. 사용자 색상은 모드에 맞게 명도를 보정하고 강조 버튼의 글자색을 대비에 따라 선택한다.
- 인증된 작업 공간의 공통 버튼·활성 메뉴·탭·배지·아바타·대시보드 강조/그라데이션·AI·WBS 강조 영역을 개인 색상 토큰으로 연결했다. 성공/오류/경고, 외부 브랜드, 이미지와 수동 Mermaid 스타일은 일괄 치환하지 않는다.
- 아키텍처 SVG와 Mermaid도 개인 색상을 반영한다. 모드가 같아도 강조색이 바뀌면 Mermaid를 다시 렌더링하고 SVG는 독립 출력 가능한 실제 색상을 사용한다.
- 헤더 모드 전환은 모드만 부분 저장하며, 편집 중인 강조색·토스트 초안은 유지한다. 기본 모드 자체가 미저장 상태일 때는 헤더 토글을 잠시 비활성화하고 먼저 저장/취소하도록 안내해 같은 필드의 충돌을 피한다.
- 저장/조회 시작 당시 사용자 ID·초기화 세대를 확인하여 이전 사용자의 늦은 성공/실패 응답이 새 계정의 설정·캐시·busy·테마를 덮지 못하게 했다. 캐시는 요청 소유자의 ID로만 기록한다.
- 런타임 소유 토큰으로 이전 화면의 cleanup이 새 런타임 설정을 제거하지 못하게 했다. 로그아웃/인증 레이아웃 이탈 시 개인 CSS 변수·토스트 상태를 정리하고 공개 화면의 기본 테마로 복구한다. 같은 사용자의 워크스페이스에서는 개인 설정을 공유한다.
- 409 등 저장 실패 시 초안은 유지한다. 최신 설정 재조회 후 초안을 재적용할 수 있는 버튼을 제공한다. 서버는 기존처럼 세션의 user.id만 사용하며 타인 ID를 요청에서 받지 않는다.

## DB 변경 및 적용

- `user_preferences.accent_color TEXT DEFAULT NULL` 컬럼을 추가했다. NULL 또는 정확한 6자리 HEX만 허용하는 CHECK 제약을 포함한다. 기존 토스트·모드·버전·사용자 키는 유지했다.
- API의 조회/기본값/허용 키/부분 갱신/응답과 SSR 초기 데이터에 accentColor를 추가했다. undefined는 기존 값 보존, null은 기본색 복원으로 구분한다.
- 실제 설정 DB의 컬럼 이름과 관련 migration 이력만 확인했다. 기존 토스트 컬럼은 있으나 023 적용 이력은 없는 상태가 계속 존재했다. 해당 기존 스키마/이력은 변경하지 않았다.
- 새 컬럼 및 027 미적용을 확인한 뒤 **027만 트랜잭션으로 적용하고 schema_migrations에 기록**했다. 기존 업무 데이터를 일괄 갱신하거나 삭제하지 않았다.

## 미완료·범위

- 요청 기능 구현의 미완료 사항 없음. 상위 탭 URL은 유지하고 하위 탭은 로컬 상태로 처리했다. 다른 브라우저 탭과의 즉시 자동 동기화는 추가하지 않았으며 DB 저장 후 재조회/재로그인으로 적용한다.
- 화면 이탈 시 미리보기를 저장값으로 복구한다. 초기 HTML은 기존처럼 기본 테마로 시작하고 인증 레이아웃의 사용자 설정을 hydration 시 useLayoutEffect로 적용한다. JavaScript가 늦게 로드될 때의 기본색 순간 노출 가능성은 기존 방식에 남아 있다.
- 기존 023 migration 이력 불일치는 별도 정비 대상이다. 이번 027은 적용 완료했으므로 중복 적용하지 않는다.
