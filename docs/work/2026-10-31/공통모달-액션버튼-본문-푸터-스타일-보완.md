# 공통 모달 액션 버튼 크기 및 본문·푸터 그림자 보완

- 작업일: 2026-10-31 (한국시간)

## 주요 변경사항

- 공통 모달 하단의 확인·저장·추가·취소·삭제 버튼에 동일한 높이 32px, 최소 폭 80px, 좌우 여백 12px, 모서리 6px, 글자 12px 규칙을 적용했다. 긴 안내 문구는 폭이 늘어나 잘리지 않으며 터치 환경에서는 버튼 높이를 모두 36px로 맞춘다.
- 화면별 기본 버튼 높이·여백이나 모바일 flex 규칙이 달라도 공통 푸터 안에서는 같은 크기를 사용하도록 선택자 우선순위를 지정했다. 기본/강조/삭제 버튼의 색상과 disabled 동작은 유지한다.
- 본문은 안쪽 그림자, 푸터는 위쪽 그림자로 영역을 구분했다. 라이트·다크 테마별 그림자 강도를 공통 CSS 변수로 관리한다.
- 팀 공유·채팅방·도움말과 기존 프로젝트 등록/확인 모달에 같은 규칙을 적용한다. 헤더 닫기 버튼은 기존 compact 크기를 유지한다.
