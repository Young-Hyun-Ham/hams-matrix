# WBS 일정 및 AI 마일스톤 이미지

`wbs-schedule.tsx`의 일정·공수 표 위에 미리보기와 PNG 이미지 다운로드를 표시합니다. 버튼은 프로젝트 전체 WBS를 기준으로 동작합니다.

- 이미지가 없으면 모델 조회·선택과 추가 요청 입력 모달을 엽니다.
- 생성 성공 시 PNG를 AES-256-GCM으로 암호화해 DB에 저장한 뒤 요청한 미리보기 또는 다운로드 모달로 이동합니다.
- 이미지가 있으면 모델 조회와 AI 호출 없이 저장한 이미지를 사용합니다.
- 미리보기의 다시 생성은 모델 선택 모달을 엽니다. 새 이미지 저장이 성공해야 기존 이미지를 교체합니다.

아키텍처와 `components/shared/ai-image-actions.tsx`를 공유합니다. 모델 조회·AI 호출·암호화도 기존 `lib/ai/image-generation.ts`, `image-crypto.ts`를 사용합니다. 생성/재생성에는 프로젝트 편집 권한, 조회/다운로드에는 프로젝트 조회 권한이 필요합니다.

## 데이터와 시각화

`lib/ai/wbs-image-prompt.ts`는 서버에서 작업명·코드·유형·단계·계획/실제 날짜·상하위 관계·선행 관계·공수·진척률을 전달합니다. 프로젝트 범위의 WBS 데이터와 프로젝트명을 해시해 원본 변경을 검사합니다. 작업 추가·수정·삭제, 선행 관계 및 프로젝트명 변경도 감지합니다. 생성 중 원본이나 권한이 바뀌면 이미지 교체를 중단합니다.

프롬프트는 연도/분기 축, 단계별 보라색 막대, 실제 날짜의 금색 마일스톤, 선행 연결선, 왼쪽 작업/기간 목록과 범례를 지시합니다. 작업 수가 많으면 단계별로 묶어 가독성을 확보하되 모든 등록 마일스톤과 날짜를 유지하도록 합니다. 등록되지 않은 마일스톤·날짜·선행 관계는 만들지 않도록 지시합니다. 월/주 단위가 적절한 짧은 일정은 축을 조정하도록 합니다.

신규 GPT Image 2 이상 모델에는 `2560x1024`, 이전 모델에는 호환되는 `1536x1024` 고품질 PNG를 요청합니다. 실제 AI 결과의 날짜·문자·배치 품질은 생성 후 확인해야 합니다. 유료 생성을 자동으로 실행하지 않습니다.

## 저장과 API

`pnpm db:migrate`로 `013_wbs_images.sql`을 적용합니다. 기존 AI API 키와 이미지 암호화 키를 그대로 사용합니다.

- `GET /api/projects/:projectId/wbs/image`: 현재 원본 해시와 저장 이미지 메타데이터.
- `POST .../image`: `{model,prompt,sourceHash,regenerate?,expectedImageId?}`.
- `GET .../image/content?imageId=:id`: 권한 검사 후 복호화한 PNG. `download=1`이면 첨부 다운로드.

프로젝트별 생성 잠금으로 중복 요청을 방지합니다. 저장 이미지 조회는 캐시하지 않습니다. 원본이 바뀌어도 저장 이미지는 유지하고, 모달에 이전 데이터로 생성된 이미지임을 표시합니다.

## 검증

`pnpm test:ai-images`는 아키텍처와 WBS의 실제 API 라우트·인증·임시 SQLite·암호화를 검사합니다. WBS 날짜·마일스톤·선행 관계 전달, 저장 이미지 재사용, 변경 감지, 중복 생성 차단, 재생성 실패 시 보존을 포함합니다. 외부 AI 응답만 대체하므로 유료 생성은 발생하지 않습니다.
