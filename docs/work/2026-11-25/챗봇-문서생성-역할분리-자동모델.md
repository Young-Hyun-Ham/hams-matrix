# 챗봇 문서 생성 역할 분리·자동 모델

- 작성일: 2026-11-25 (Asia/Seoul)
- 요구사항: 첨부한 일반 채팅/@document 비교표를 기능 기준으로 반영한다. ☰와 /의 파일 생성 명칭을 문서 생성으로 바꾸고, 모델을 선택하는 대신 완성된 문서를 제작하는 역할을 제공한다.

## 주요 변경사항

- 메뉴·입력 모드 문구를 문서 생성으로 바꿨다. 문서와 이미지 생성 모드에서는 모델 목록 조회/선택을 하지 않고 서버가 허용된 기본 모델을 결정한다. 일반 채팅에만 모델 선택을 제공한다. 클라이언트가 생성 모드에 modelId를 보내도 서버에서 무시한다.
- 문서 생성 전용 지침으로 목적·독자·문서 종류에 맞는 제목, 필요 시 목차, 절/소절, 도입/본문/결론, 목록과 표를 구성한다. 참조 자료는 데이터로 취급하며 근거 없는 사실·수치·출처를 만들지 않도록 지시한다.
- 결과물 카드에 명시적으로 여는 문서 미리보기를 추가했다. Markdown 제목·목록·표·본문 내 이미지를 표시하며 HTML과 외부 이미지 로딩을 허용하지 않는다. 개인 생성물의 기존 소유자·공개 버전·삭제 방·무결성 검증을 거쳐 본문을 조회한다.
- 이미지 분석용 참조와 본문 삽입을 구분한다. 사용자가 삽입을 요청한 경우 모델은 위치 표식을 반환하고 서버가 검증된 첨부 이미지로 치환한다. 다운로드한 Markdown 파일에도 이미지 데이터가 포함된다. 수정 시 포함 이미지를 다시 추출해 문맥과 삽입 번호를 유지하며 최대 6개로 제한한다.
- 생성물 다운로드·수정 버전·HITL 승인/거절을 유지한다. 완료 모델 응답은 저장된 결과를 재사용한다. 모델 선택을 숨겨도 서버의 허용 모델·쿼터·정책 검사와 사용량 기록은 유지한다.

- lib/chatbot/document.ts(신규), providers.ts, repository.ts, generation.ts, storage.ts
- scripts/test-chatbot.mjs, scripts/test-chatbot-browser.mjs
- README.md, AGENTS.md, CLAUDE.md, WORK_HISTORY.md 및 이 기록

## DB 변경

- 없음. 기존 file 모드·생성물 종류와 Markdown/텍스트 형식을 유지해 기존 이력·생성물·검토 요청을 보존한다. 명칭 변경을 이유로 자료를 이전하거나 과거 행을 수정하지 않았다.

## 검증

- 임시 DB·메모리 객체 저장소·모의 공급자 통합: 88개 통과. 모델 덮어쓰기 무시, 문서 전용 지침, 소유자 외 본문 접근 거절, 첨부 이미지 삽입/수정/검토 승인, 기존 정책 재개·시나리오·AI 자료 보존 포함.
- Chrome 회귀: 20개 통과. 문서 생성 명칭, 문서·이미지 모드의 모델 선택창 제거, 슬래시 명령·기존 테마·시뮬레이터 포함.
- 전체 TypeScript 검사와 변경 파일 ESLint 통과(오류/경고 0개). 전체 production build는 이번 후속 변경에서 반복하지 않았다.
- 실제 유료 공급자나 운영 데이터로 생성 테스트를 하지 않았다.

## 운영 및 범위

- 서버 전용 CHATBOT_DOCUMENT_MODEL로 문서 기본 모델을 지정할 수 있다. 없으면 기존 CHATBOT_TEXT_MODEL 및 허용 모델 기본값을 따른다. 실제 키/설정값은 이 문서에 기록하지 않는다.
- 현재 문서 형식은 Markdown/텍스트다. 텍스트 형식은 표와 이미지 내용을 문자로 표현하며 이미지를 포함하려면 Markdown을 사용한다. Office/PDF 형식 추가는 이번 변경에 포함하지 않았다.
- 문서의 내용/구성은 모델이 작성하므로 검토가 필요하다. 기존 문서 수정은 승인 이후에만 현재 버전으로 반영한다.
- 미완료 사항: 없음. 실제 유료 모델의 작성 품질과 Office/PDF 출력은 이번 검증 범위 밖이다.
