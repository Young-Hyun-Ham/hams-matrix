# 플래닝보드 미리보기 현재 편집 상태 사용

- 작성일: 2026-11-05 (한국시간)

## 주요 변경사항

- 기존 미리보기는 부모 편집기의 메시지를 기다리는 동시에 저장된 보드를 조회하여, 메시지보다 DB 응답이 빠르면 저장본이 먼저 보일 수 있었다.
- 헤더에서 연 창처럼 `previewNonce`가 있는 미리보기에서는 저장된 보드 조회를 실행하지 않고, 버튼 클릭 시점의 편집 스냅샷만 수신한다. 메시지가 오지 않아도 저장본으로 대체하지 않는다.
- nonce 없는 미리보기 URL 직접 접속은 기존 저장본 조회를 유지한다. 로그인·접근 권한 확인 동작은 유지한다.
- 직접 접속 조회의 늦은 응답이 컴포넌트 해제 후 상태를 갱신하지 않도록 정리 플래그를 추가했다.
- 메모리의 전체 편집 상태와 현재 선택 요소가 속한 페이지 ID를 전달하는 기존 부모 흐름은 유지하며 query 역할을 소스 주석에 설명했다.

## query와 데이터 전달 흐름

1. `new URLSearchParams(window.location.search)`는 현재 주소의 `projectId`, `screenId` 등 query를 복사한다.
2. `query.set("previewNonce", nonce)`는 이번 미리보기 창을 식별하는 임의 UUID를 추가하거나 기존 값을 교체한다.
3. `window.open`의 URL 안에 `${query}`를 넣으면 query가 문자열로 직렬화되어 새 창 주소에 붙는다. 문서 내용 자체를 URL로 보내는 것은 아니다.
4. 새 창은 같은 nonce로 `preview-ready`를 보내고, 부모는 `postMessage`로 `layers`, `sizes`, `positions`, `layerText`, `layerImages`, `layerStyles`, `activePageId` 등 현재 편집 데이터를 전달한다.
5. 수신 창은 origin·부모 창·nonce를 확인한 뒤 해당 스냅샷을 표시한다. nonce는 로그인 토큰이나 DB 조회용 문서 ID가 아니라 두 창의 메시지를 연결하는 일회성 식별자다.
