# 플래닝보드 전체 패널 공통 다크 테마

- 작성일: 2026-11-04 (한국시간, Asia/Seoul)

## 주요 변경사항

- `styles/dark-theme.css`에서 Matrix의 surface·canvas·ink·muted·line·primary 토큰으로 다크 UI를 공통 관리한다. 기존 라이트 스타일은 수정하지 않았다.
- 헤더·좌우 패널·캔버스 도구막대에 배경뿐 아니라 버튼·아이콘·입력·보조 글자·경계선을 적용했다. 선택·호버·비활성·포커스·주요 작업·삭제 상태도 함께 처리한다.
- 캔버스 작업 배경과 점 격자, 확대 메뉴·우클릭 메뉴·댓글·선택 핸들을 다크 테마에 연결했다. 이력·공유/검토 모달·오류 안내와 미리보기의 UI에도 같은 규칙을 사용한다.
- 작성한 페이지·요소·이미지·메모의 배경색은 문서 데이터로 유지한다. 작업 배경을 어둡게 만들기 위해 설계 문서를 반전하거나 다시 저장하지 않는다.

## 변경 파일

- 신규 `app/(editor)/planning-board/styles/dark-theme.css`.
