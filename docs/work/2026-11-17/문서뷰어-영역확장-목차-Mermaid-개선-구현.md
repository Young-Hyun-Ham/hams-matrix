# 문서 뷰어 영역 확장·목차·Mermaid 개선 구현

- 작성일: 2026-11-17 (한국시간, Asia/Seoul)
- 기준: [최신 설계 문서](../../history/2026-11-17/문서뷰어-영역확장-목차-Mermaid-개선-설계.md)를 다시 읽고 권고안을 적용했다. 기존의 다른 미커밋 변경은 보존한다.
- 상태: 구현 및 관련 검증 완료.
- 후속 변경: 같은 날 사용자 요청으로 아래 40단위 목차 폭 정책을 취소하고 본문:목차를 7:3으로 변경했다. 이 문서는 당시 구현·검증 이력이며 현재 정책은 [비율 조정 기록](문서뷰어-본문목차-7대3-비율조정.md)을 따른다.

## 주요 변경사항

- 본문 열의 900px 상한을 제거했다. 전역 메뉴를 접어 확보한 공간을 문서 본문도 사용하며, 목차 없는 문서는 빈 열 없이 1열로 표시한다.
- 목차 제목은 한글 2·그 외 1의 합계 40단위를 기준으로 한다. 300px 기준값에 현재 글꼴의 W 40개·한글 20자·40단위 이하 실제 제목의 측정 폭과 여유 폭을 반영한다. 긴 제목은 한 줄 말줄임과 전체 제목 안내를 제공한다.
- 목차는 고정 제목 아래 목록만 스크롤한다. 스크롤바는 숨기며 휠·트랙패드·키보드 이동을 유지한다. 제목과 외곽 여백의 세로 휠도 목록으로 전달하고, 목록 끝에서 본문으로 스크롤이 이어지지 않도록 했다.
- 목차 표시 여부는 실제 읽기 영역 폭에서 본문 최소 500px·목차 실측 폭·간격·여백을 확보할 수 있는지로 판단한다. 글꼴 보정으로 목차가 넓어지면 설계의 초기 1120px 경계도 함께 넓어진다.
- Mermaid fenced block에 독립적인 ‘텍스트/미리보기’ 탭을 추가했다. 기본은 텍스트이며 선택 시 지연 도식화한다. flowchart·sequence·class·state·ER·gantt를 지원하고 오류는 해당 블록 안에 표시한다.
- 문서 전체 원문 편집·저장과 저장된 본문 기준 미리보기는 유지한다. fence 내부의 # 제목은 목차에서 제외한다.
- SVG 정리·라벨 대비 보정을 공통화하고 SVG CSS를 해당 도식 ID 아래로 제한했다. Mermaid 초기화·파싱·렌더를 기존 아키텍처와 직렬화하며 문서 전환·해제 후 오래된 렌더 결과를 폐기한다.
- 통합 검증에서 발견한 기본 스타일 제거와 목차 행 압축을 수정했다. SVG 기본 CSS는 보존하되 불필요한 at-rule을 제거하고, CSS 자식 선택자는 CDATA로 직렬화해 보존한다. 긴 목차에서도 각 행의 높이를 유지한다.

## 변경 파일

- `app/(workspace)/viewer/md/MarkdownViewer.tsx`: 가변 본문·목차 측정·휠 처리·fence 제목 제외·안정적인 Mermaid 블록 renderer.
- `app/(workspace)/viewer/md/MermaidBlock.tsx` (신규): 읽기 전용 탭·지연 도식화·테마·오류·키보드 접근성.
- `styles/pages/viewer/md/MarkdownViewer.module.css`: 본문·목차 레이아웃, 숨김 스크롤, Mermaid UI.
- `lib/mermaid-preview.ts` (신규): 공통 SVG 정리·CSS 격리·라벨 대비 보정.
- `lib/mermaid-render.ts` (신규): 공유 설정 충돌을 막는 렌더 직렬화와 문서용 입력 정책.
- `components/pages/architecture/mermaid-preview.ts`, `architecture-mermaid.tsx`: 공통 helper 재export 및 렌더 경계 연결. 기존 저장·dirty·AI 생성 정책은 유지한다.
- `scripts/test-viewer.mjs`: 폭·40단위 제목·실제 휠·여섯 도식·오류·테마·취소·반응형 검증 추가.
- `scripts/test-architecture-mermaid-browser.mjs`: 공통 helper 및 CSS 격리·입력 정책 검증 보강.
- `README.md`, `AGENTS.md`, `CLAUDE.md`, `WORK_HISTORY.md`: 기능 안내·유지보수 기준·작업 링크 추가.

## DB 변경 여부

DB·마이그레이션 변경 없음. 패키지·잠금 파일·문서 로딩과 저장 API·접근권한 계약 변경 없음. 브라우저 회귀는 별도 합성 Markdown과 임시 SQLite만 사용한다.

## 검증 결과

- 변경 파일 ESLint: 통과. `node node_modules/eslint/bin/eslint.js`로 뷰어·공통 helper·아키텍처 연결부와 검증 스크립트를 확인했다.
- TypeScript: `pnpm typecheck` 통과. 최종 프로덕션 빌드의 TypeScript 검사도 통과했다.
- `node node_modules/next/dist/bin/next build`: 통과(종료 코드 0). 67개 정적 페이지와 전체 경로 생성 완료. 정적 생성 중 `Request failed Error` 로그가 여러 번 출력됐으며, 원인은 이번 범위에서 별도 분석하지 않았다. 빌드 실패는 없었다.
- `node scripts/test-architecture-mermaid-browser.mjs`: 통과. 실제 graph/classDef/subgraph·네이티브 SVG 텍스트·다크 테마의 밝은 노드 대비, SVG CSS/실행 요소 격리, 자식 선택자 보존, 설정·외부 링크·이미지 문법·빈 코드·크기 제한을 확인했다.
- `node scripts/test-viewer.mjs`: 최종 전체 통과. 1920px에서 메뉴 접기 시 본문이 176px 넓어져 900px 상한을 넘는 것을 확인했다. h1~h3의 한글 20자·영문 40자·혼합 40단위·W 40개가 한 줄이고 행 높이도 유지됐다.
- 같은 뷰어 회귀에서 실제 브라우저 휠로 목록·목차 제목 위 이동과 양 끝의 스크롤 격리를 확인했다. 여섯 종류 도식의 주요 라벨, 오류·빈 코드·설정 차단, 라이트/다크 전환, 키보드 탭 이동, 문서 전환 시 결과 폐기, 목차 없는 문서 1열을 검증했다.
- 1600/1440/1200/1000/720/390px 및 viewport와 독립적인 중첩 페이지 폭 변경에서 가로 넘침과 목차 표시를 확인했다. 기존 검색·상대 문서 링크·문서 탭·원문 초안·저장 실패·설정 화면 스타일 왕복·브라우저 이력 검증도 통과했다. 실제 AI 대화 패널 조작 대신 중첩 페이지 폭 변경으로 컨테이너 반응을 검증했다.
- 이번 변경 대상 외 기존 882개 파일은 작업 전후 내용 해시가 일치했다. 기존 설계 문서·다른 미커밋 변경과 패키지·마이그레이션을 보존했다. 작업 기록 링크도 정상이며 변경 파일 대상 `git diff --check`를 통과했다. 전체 diff에는 기존 `PROMPT.md`의 후행 공백 경고가 있어 해당 파일은 수정하지 않았다.
- 설치 의존성 접근 제한으로 최초 샌드박스 검사는 실패했다. 권한 확장 후 직접 Node 실행으로 검증을 진행했다. 프로젝트 의존성은 변경하지 않았다.

## 미완료 및 범위

- 요청 범위의 구현·검증 미완료 없음. 빌드의 요청 실패 로그는 위에 기록한 별도 확인 사항이다. 검증 과정에서 발견한 테스트 선택자 범위, SVG 기본 색상, 목차 행 높이 문제는 수정 후 전체 회귀를 통과했다.
- 내부 250px 문서 목록의 별도 접기, 모바일 목차 오버레이, 미저장 초안 미리보기, 지원 목록 외 Mermaid 종류, 도식 확대·저장은 이번 범위에 포함하지 않는다.
- 목차가 숨김에서 표시로 전환되는 경계에서는 새 목차 열도 공간을 사용한다. 확장 보장은 문서 내용 패널 기준이며, 같은 목차 표시 상태에서는 본문 종이도 확보된 폭만큼 확장한다.
