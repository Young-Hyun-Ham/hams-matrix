# 프로젝트 등록 모달 공통 스타일 통일

- 작업일: 2026-10-30 (한국시간)

## 주요 변경사항

- WBS·아키텍처·요구사항·화면·DB·프로그램·테스트의 공통 등록/수정/상세 모달에 기존 compact 공통 모달 스타일을 적용했다.
- 새 프로젝트 생성 모달도 같은 헤더·닫기 버튼·본문 스크롤·하단 버튼 영역을 사용한다.
- 공통 스타일을 `styles/dialog.css`의 `project-registration-dialog`, `project-registration-body`, `project-registration-footer`로 관리한다. 기본 최대 폭은 820px이며 구성요소 편집이 필요한 아키텍처는 1000px 확장 규칙을 사용한다.
- 아키텍처 전용 모달 스타일과 분기를 제거하고 공통 규칙으로 통합했다. 입력·검증·저장·취소·저장 중 닫기 방지 및 읽기 전용 권한 동작은 유지했다.
- 등록 모달 범위 밖인 삭제 확인, 이미지 생성, 전체 일정/제안요청서 미리보기 및 팀 관리 모달은 기존대로 유지했다.
