# AI 대화 10개 페이징 및 이전 대화 자동 조회

- 작성일: 2026-11-10 (한국시간)

## 주요 변경사항

- 채팅방을 열면 최신 대화 10건을 시간 순서로 표시하고 대화 영역의 맨 아래로 이동한다. 질문과 AI 답변 한 쌍을 1건으로 센다.
- 위쪽으로 스크롤하면 이전 10건을 자동 조회한다. 기존 rowid 커서를 사용하며 마지막 페이지는 남은 건수만 표시한다. 모든 기록을 읽으면 추가 조회를 중단한다.
- 이전 내용을 위에 추가해도 읽던 메시지의 화면 위치를 유지한다. 조회 중 사용자가 추가로 스크롤한 위치도 반영하며, 바깥 페이지를 강제로 스크롤하지 않는다.
- 중복 요청·메시지를 방지하고 닫기·재조회·방 전환 시 진행 중 이전 조회를 취소한다. 늦게 도착한 응답을 무시해 다른 방의 내용과 섞이지 않도록 했다.
- 이전 페이지 조회 실패 시 이미 표시한 대화를 유지하고 오류를 위에 표시한다. 자동 재시도 반복을 막고 기존 “이전 대화 더 보기” 버튼으로 재시도할 수 있다.
- 새 답변 추가·채팅창 재열기 시 최신 위치로 이동한다. 기존 대화 저장, 첨부 조회 범위, AI 생성에 전달하는 최근 문맥 제한은 유지했다.

## 변경 파일

- `lib/ai/conversations.ts`: 조회 크기 10건 및 다음 페이지 확인용 1건.
- `components/ai/use-ai-conversation.ts`: 이전 조회 오류 분리·중복 제거·취소 및 초기 조회 갱신 상태.
- `components/ai/ai-conversation-messages.tsx`: 상단 자동 조회·읽던 위치 보존·초기/최신 하단 이동·오류 재시도.
- `components/ai/ai-chatbot.css`: 브라우저의 자동 스크롤 앵커링과 수동 위치 복원 충돌 방지.
- `components/ai/README.md`: 조회 방식과 검증 명령 갱신.
- `scripts/check-ai-conversations.mjs`: 기존 HTTP 통합 검증의 50건 기대값을 10건 다중 페이지로 보정.
- `scripts/test-ai-chat-pagination.mjs`, `scripts/test-ai-chat-pagination-browser.mjs`: API·브라우저 검증 추가.
- 본 작업 기록과 `WORK_HISTORY.md` 링크 추가. 기존의 다른 변경사항은 보존했다.

## DB 변경 여부

- 스키마·마이그레이션·운영 데이터 변경 없음. 기존 저장 구조와 rowid 커서를 그대로 사용한다.
- 서버 검증은 임시 SQLite에만 테스트 데이터를 생성했다. 외부 AI 호출이나 유료 생성은 수행하지 않았다.

## 검증 결과

- `node scripts/test-ai-chat-pagination.mjs`: 통과. 실제 인증·GET API로 0/1/10/11/20/25/55건, 동일 저장 시각의 순서, 누락·중복, 중간 신규 삽입, 같은 커서 재조회, 첨부 메타데이터, 사용자/프로젝트/공통 방 범위와 비정상 커서를 검사했다.
- `node scripts/test-ai-chat-pagination-browser.mjs`: 통과. 실제 React 대화 훅·컴포넌트와 모의 조회 응답으로 초기 10건/하단 위치, 자동 이전 조회, 조회 도중 스크롤을 포함한 위치 유지, 중복 요청 방지, 오류 후 기존 대화 보존·재시도, 마지막 5건, 조회 종료, 새 답변·재열기·방 전환·빈 방을 검사했다.
- TypeScript 및 변경 파일 ESLint: 통과.
- 변경 TS/TSX/검증 스크립트의 Prettier 검사 및 `git diff --check`: 통과.
- 기존 전체 `pnpm test:ai` HTTP 묶음은 별도로 실행하지 않았다. 이번 기능은 위의 독립된 실제 GET API·브라우저 검사로 검증했다.
