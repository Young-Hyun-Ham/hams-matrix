# 제안요청서 작성 탭 구현

- 작성일: 2026-10-30 (한국시간)
- 기준 문서: `docs/history/2026-10-30/제안요청서-작성탭-설계.md`

## 주요 변경사항

- 프로젝트의 `개요` 바로 뒤에 `제안요청서` 탭을 추가했다.
- 왼쪽 문서 목차와 오른쪽 장별 작성 영역으로 구성한 샘플 작성 화면을 추가했다.
- 사업 개요, 추진 범위, 세부 요구사항, 수행 및 관리, 제안 안내, 평가 기준, 부록을 작성할 수 있다.
- 요구사항·주요 일정·평가 항목의 추가, 수정, 삭제를 지원한다.
- 필수 항목 작성 수와 장별 `미작성 / 작성 중 / 입력 완료` 상태를 표시한다.
- 사업기간, 예산, 요구사항 번호 중복·필수값, 평가 배점을 확인하고 해당 장에 안내한다.
- 현재 입력값을 문서 형태로 조합하는 전체 미리보기 모달을 추가했다.
- 샘플 편집 상태를 workspace·사용자·프로젝트 단위 메모리에 보관하여 탭 왕복 시 유지하고, 새로고침 시 초기화한다.
- 프로젝트의 `canWrite`가 false이면 입력·추가·삭제·초기화를 막고 미리보기만 제공한다.
- 새 탭에서 AI 패널을 열어도 오류가 나지 않도록 조회 전용 안내 프롬프트와 탭 분기를 추가했다. AI는 샘플 입력값을 조회하거나 저장하지 않는다.
- 반응형 배치, 테마 변수, 입력 라벨, 키보드 포커스, 모달 Esc 닫기와 초점 복귀를 적용했다.

## DB 변경 여부

DB 변경 없음. 기준 문서의 1차 범위는 서버 저장 전 샘플 화면이며, 입력값은 메모리에만 유지한다. 실제 저장 API, DB 구조, 버전 관리, 기존 요구사항 연계는 후속 결정 사항이다.

## 검증 결과

- 변경 대상 TypeScript/TSX 파일 ESLint 통과.
- `git diff --check` 통과.
- 실행 중인 Next.js 개발 서버에서 `/projects/sample?tab=rfp` 요청이 HTTP 200으로 응답했고 변경 후 컴파일 로그에 새 오류가 없음을 확인했다.
- `pnpm typecheck` 실행. 새 제안요청서 관련 오류는 없었으나 저장소의 기존 오류로 전체 검사는 실패했다.
  - `.next/types/validator.ts`가 현재 존재하지 않는 레거시 페이지 모듈을 참조한다.
  - `app/(workspace)/viewer/md/MarkdownViewer.tsx`에서 `react-markdown`, `remark-gfm` 모듈 해석 및 관련 암시적 `any` 오류가 있다.
