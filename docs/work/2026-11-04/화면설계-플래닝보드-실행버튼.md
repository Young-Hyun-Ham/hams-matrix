# 화면설계 탭 플래닝보드 실행 버튼

- 작성일: 2026-11-04 (한국시간, Asia/Seoul)

## 주요 변경사항

- 화면설계 목록에 전용 `플래닝보드` 열을 추가하고 각 화면에 `플래닝보드 실행` 버튼을 표시했다.
- 기본 강조색과 새 창 아이콘으로 구분하고, 화면 이름과 새 창 실행 여부를 접근성 이름에 포함했다.
- 클릭하면 해당 projectId·screenId의 `/planning-board`를 새 창으로 연다. READ 권한 사용자에게도 표시하며 실제 편집 권한은 기존 보드 인증·권한 검사를 따른다.
- 기존 수정·상세·삭제 작업과 저장 후 목록 갱신 흐름을 유지했다. 공통 목록의 전용 실행 열은 선택 사항이므로 다른 탭의 구성은 유지된다.

## 변경 파일

- `components/pages/screens/screens-page.tsx`: 전용 열과 강조된 실행 버튼.
- `components/shared/artifact-list.tsx`: 선택적 읽기 작업 열 지원.
- 본 기록 및 `WORK_HISTORY.md`.
