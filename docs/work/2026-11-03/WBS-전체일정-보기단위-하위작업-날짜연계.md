# WBS 전체 일정 보기 단위 및 하위 작업 날짜 연계

- 작성일: 2026-11-03 (한국시간)

## 주요 변경사항

- 전체 일정 미리보기와 확대 화면에 WBS 화면에서 선택한 일간·주간·월간 상태를 전달한다.
- 일간은 날짜별, 주간은 표시 시작일 기준 7일 간격, 월간은 월 경계 기준으로 눈금과 라벨을 표시한다. 확대 차트의 날짜당 폭도 보기 단위에 맞춰 조정하며 작업 막대의 실제 시작·종료일은 유지한다.
- 하위 작업 추가 모달의 시작일·종료일에 현재 상위 요약 작업의 날짜를 기본값으로 제공한다. 기존 일정 집계와 미저장 편집을 반영한 `normalized` 데이터에서 읽는다.
- 상속한 날짜는 기존 입력란에서 변경할 수 있다. 최상위 신규 작업은 기존처럼 오늘 날짜를 기본값으로 사용한다.

## 변경 파일

- `components/pages/wbs/wbs-schedule-chart.jsx`: 선택된 보기 단위를 미리보기 컴포넌트로 전달.
- `components/pages/wbs/wbs-overview.tsx`: 보기 단위별 라벨·눈금·확대 배율.
- `components/pages/wbs/use-wbs-schedule.ts`: 하위 작업 날짜 기본값.
- `scripts/test-wbs-view.mjs`: SVG 렌더링 및 하위 작업 날짜 동작 검증.
- `WORK_HISTORY.md`: 작업 기록 링크.
