# 의도분류 참조 지식 목록·상세 개선

- 목록에 처리 의도와 별도로 참조 업무, 대표 자료명, 검색 상태, 자료/청크 참조 건수를 표시한다. 업무 영역은 실제 참조 자료 기준이며 질문 의도의 추정 결과로 표시하지 않는다.
- 상세는 자료별 제목·버전·검색 내용 미리보기와 당시 내용/현재 원본 정보 링크를 앞에 둔다. 분류 코드, 이벤트/검색본/자료/청크 ID는 닫힌 기술 정보에 둔다. 숫자 버전은 vN, SHA-256은 축약한 변경 식별자로 표시한다.
- 저장 검색본과 자료 유형/ID/버전/청크 ID가 모두 일치하면 당시 제목과 내용을 사용한다. 당시 청크가 없으면 현재 제목임을 명시한다. 현재 원본이 삭제되었거나 열람 불가하면 과거 제목과 미리보기도 숨긴다.
- 자료명·미리보기는 목록 20건에 대해 현재 자료/READ 검사를 한 번 수행하고 청크를 묶어서 조회한다. 파일 다운로드, AI 호출, 개인 대화 JOIN/질문 요약 복원, DB migration, 새 폴링은 없다.
- WBS 등 완전한 산출물 JSON 청크는 기존 필드 정의의 항목명으로 최대 280자 미리보기를 만든다. 일반 청크/부분 JSON은 저장된 텍스트를 최대 280자로 표시한다. 전체 당시 내용은 기존 읽기 전용 참조 상세창에서 확인한다.
- 기존 실패 이력 분리, owner/이력 플랜/workspace 범위, 필터 초안/커서/참조 URL/닫기/테마 정책을 유지한다.
- 격리 API 회귀에 당시/현재 제목 구분, 실제 참조 업무, WBS 항목 미리보기, 버전/자료 불일치 차단, 삭제 원본의 과거 제목/내용 숨김을 추가했다. 브라우저 회귀에 자료명/미리보기/기술 정보 접힘과 삭제 자료 직접 링크 검증을 추가했다.
- 통과: `pnpm test:intent-classifications`, 타입 검사, 변경 파일 ESLint, `pnpm build`.
- 통과: `pnpm test:intent-classifications-browser` — 자료명/미리보기/기술 정보 접힘, 삭제 자료 직접 링크, 320~1440px 화면, 기존 상세 링크/버전/테마/필터/권한/실패 이력 회귀. `.auth-tests/intent-console/knowledge-desktop.png` 화면 확인 완료.
