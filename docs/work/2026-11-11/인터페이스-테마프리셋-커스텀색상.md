# 인터페이스 테마 프리셋 및 커스텀 색상 잠금

- 작성일: 2026-11-11 (한국시간)
- 요구사항: 기본테마 선택 항목 제거, 이미지 형태의 라이트/다크 각 3개와 커스텀 버튼 추가. 강조 색상/HEX는 커스텀에서만 편집.

## 주요 변경사항

- 기본테마 select 대신 주황·파랑·초록 3종의 라이트/다크 총 6개 스와치와 커스텀 1개를 추가했다. 선택 테두리·체크 표시·제목/접근성 이름·키보드 방향키/Home/End 선택을 지원한다.
- 프리셋은 밝기와 고정 강조 색상을 함께 미리보기한다. 강조 색상·HEX·기본 색상 복원 버튼을 비활성화한다. API에서도 프리셋의 임의 색상 변경을 거부한다.
- 커스텀은 현재 밝기와 색상을 이어받아 자유롭게 편집한다. 같은 색상이 프리셋과 일치하더라도 커스텀 선택 자체가 저장된다.
- 기존 테마와 사용자 색상은 custom으로 보존한다. 세 인증 레이아웃의 초기 설정/hydration·Zustand preview/save/cancel·사용자 격리에 새 선택값을 연결했다.
- 헤더 밝기 전환은 프리셋의 색상 계열을 유지하며 light/dark 짝으로 저장한다. 테마 선택 초안이 있으면 저장/취소 전 헤더 전환을 잠가 혼합 상태를 방지한다. 토스트 설정은 기존 동작을 유지한다.

## DB 변경

- 044 마이그레이션으로 `user_preferences.theme_preset` 추가. 기본 custom·NOT NULL·7개 허용값 CHECK 제약 적용.
- 구성된 DB의 043 적용을 확인한 후 **044만 적용 및 컬럼 확인 완료**. 기존 개인 설정 색상·테마·버전은 수정하지 않았다. 중복 적용하지 않는다.
- API/브라우저 테스트는 별도 임시 SQLite를 사용한다. 운영 DB에 테스트 계정·업무 데이터·민감정보를 생성하거나 기록하지 않는다.
