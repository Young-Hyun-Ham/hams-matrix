# 좌측 메뉴 아이콘 축소·로그아웃·툴팁 구현

- 작성일: 2026-11-05 (한국시간, Asia/Seoul)
- 기준: [최신 설계 문서](../../history/2026-11-05/좌측메뉴-아이콘축소-로그아웃-툴팁-설계.md)를 다시 읽고 권장안으로 구현했다.
- 진행 상태: 구현 및 관련 검증 완료.

## 주요 변경사항

- 데스크톱 메뉴 닫기를 64px 아이콘 패널로 변경했다. 기존 펼침 너비 240/214/210px를 유지하고, 본문 여백과 701~960px AI 패널·배경의 시작점을 같은 CSS 변수로 연결했다. 낮은 화면에서 스크롤바가 생겨도 버튼 클릭 영역이 잘리지 않도록 가운데 정렬했다.
- 축소 시 브랜드명·메뉴명·배지·계정 요약을 숨기고 브랜드 심벌·메뉴 아이콘·44×44px 로그아웃 버튼을 남겼다. 이름을 숨긴 메뉴에도 접근 가능한 이름을 제공한다.
- 일반 메뉴·AI 메뉴·하단 로그아웃에 portal 툴팁을 추가했다. hover 300ms, 키보드 포커스, Escape 닫기·재진입, 포인터의 툴팁 이동, 화면 경계 보정과 화면/패널 전환 정리를 지원한다.
- 축소 상태에서 AI 아이콘이나 AI 검색 결과를 누르면 패널과 목록을 펼친다. 헤더로 축소하면 목록을 닫되 선택된 대화는 유지하고, 목록·모달 언마운트 후 헤더 버튼으로 포커스를 복원한다.
- 로그아웃 API·성공/401 처리를 유지했다. 요청 중 중복 실행을 막고, 실패 시 현재 화면 상태에 따라 축소는 토스트, 펼침·모바일은 인라인 오류로 안내한다. 인라인 오류를 가진 채 축소할 때도 토스트로 옮긴다.
- 700px 이하 모바일은 기존 260px 드로어를 유지한다. 닫힌 모바일 메뉴는 `inert`로 포커스를 차단하고, 오버레이·body 스크롤 잠금을 모바일 열림 상태에만 적용한다.
- 축소 상태는 메모리에서만 유지하며 새로고침 시 펼친다. 낮은 화면에서는 기존 패널 스크롤로 하단 로그아웃에 접근한다. AI 세로 오프셋은 이번 범위에서 변경하지 않았다.

## DB 변경 여부

- 운영/개발 DB 및 마이그레이션 변경 없음. UI 변경이므로 스키마·데이터 이관이 필요 없다.
- 브라우저 테스트만 OS 임시 폴더에 별도 SQLite를 만들고 기존 마이그레이션·합성 사용자/세션을 적용한다. 실제 회원 DB를 사용하지 않으며 유료 AI 호출을 수행하지 않는다.
