# 로그인 스크립트 경고 수정 및 회원등록·로그인 버튼 너비 정리

- 작업일: 2026-10-28 (한국 시간)

## 주요 변경 사항

### 로그인 후 React 스크립트 경고 수정

- 로그인 성공 후 클라이언트 화면 전환으로 워크스페이스 레이아웃이 렌더링될 때 일반 `<script>` 태그가 삽입되어 React 경고가 발생했다.
- 워크스페이스 레이아웃의 테마 적용용 `<script>`를 제거했다.
- `PreferencesRuntime`의 설정 초기화를 `useEffect`에서 `useLayoutEffect`로 변경했다. 기존 `initialize()` → `syncTheme()` 경로를 통해 브라우저가 화면을 그리기 전에 DB의 사용자 테마를 적용한다.
- 루트 문서의 기본 테마 초기화는 유지하고 관련 주석을 현재 동작에 맞게 수정했다.

### 회원등록·로그인 버튼 너비 정리

- 로그인 화면의 `.auth-submit`에 `width: 100%`를 지정해 회원등록 링크와 로그인 버튼이 같은 폼 영역 너비를 사용하도록 했다.
- 게스트 화면 좌측 패널의 회원등록·로그인 링크를 하나의 grid 영역에 배치해 패널 안쪽 콘텐츠 너비에 맞춰 늘어나도록 했다.
- 게스트 화면의 로그인 링크에도 공통 `.button` 스타일을 적용했다. 회원등록과 로그인은 각각 `/signup`, `/login`으로 이동한다.

# 게스트 요금제 화면 통합 및 회원 요금제 변경

- 작업일: 2026-10-28 (한국 시간)

## 주요 변경 사항

- 로그인 회원과 게스트가 공통 `SubscriptionPlans` 컴포넌트로 동일한 요금제 카드·가격·한도·추천 표시를 확인하도록 변경했다.
- 게스트 요금제 화면도 샘플 문구 대신 DB에 등록된 실제 요금제 목록을 조회한다. 게스트에게는 개인 사용량, 현재 플랜, 선택 입력 및 변경 버튼을 표시하지 않는다.
- 로그인 회원은 현재 플랜 외의 요금제를 선택하고 `요금제변경` 버튼을 누를 수 있다.
- 확인 모달에 `xx 요금제로 변경 하시겠습니까?`를 표시하며, `결재` 버튼을 누르면 요금제가 즉시 변경된다. 취소 시에는 변경하지 않는다.
- 결제 시스템이 없으므로 실제 청구가 없음을 화면과 모달에 안내한다. Business도 현재 요청 범위에 따라 선택 가능하며 별도 계약·청구는 생성하지 않는다.
- 완료 후 현재 요금제와 한도를 새로 불러오고 완료 안내를 표시한다. 요청 중에는 중복 실행 및 모달 닫기를 제한하고 실패 시 모달에 오류를 표시한다.

## API 및 데이터 처리

- `PATCH /api/me/subscription`을 추가했다. 인증된 회원 자신의 구독만 변경하며 게스트와 미인증 요청은 거부한다.
- 출처, 허용 필드, 요금제 코드 및 버전을 검증한다. 현재 요금제나 선택한 요금제의 정책 버전이 변경되었으면 409를 반환한다.
- 쓰기 트랜잭션으로 구독 변경, 관리자 회원정보 버전 증가, 요금제 변경 이력 저장을 함께 처리한다.
- 동일 요금제로 요청한 경우 중복 변경 이력을 만들지 않는다.
- DB 스키마 변경은 없다. 실제 변경 요청 시 기존 `user_subscriptions`, `users`, `plan_change_logs` 데이터를 갱신한다.
- 기존 프로젝트·사용량은 삭제하거나 초기화하지 않는다. 낮은 플랜으로 변경해 한도를 초과하면 기존 한도 검사 로직에 따라 추가 사용이 제한된다.

# 상단 경로에 현재 탭 표시 및 이동 링크 추가

- 작업일: 2026-10-28 (한국 시간)

## 주요 변경 사항

- 상단 경로를 접근성 이름이 있는 `nav`로 구성하고 현재 페이지 링크에 `aria-current`를 표시했다.
- 프로젝트 화면은 `워크스페이스 > 프로젝트 작업 공간 > 현재 탭`으로 표시한다. 워크스페이스 링크는 대시보드, 프로젝트 작업 공간 링크는 개요 탭, 마지막 링크는 현재 탭으로 이동한다.
- 설정 및 관리자설정은 메뉴 이름과 현재 탭 이름을 분리해 각각 이동 가능한 링크로 표시한다.
- 프로젝트 탭 상태를 로컬 state 대신 URL의 `tab` 쿼리에서 읽도록 변경했다. 탭 클릭과 본문 내부 탭 이동 모두 Native History API로 URL을 갱신한다.
- 직접 URL 접근, 새로고침, 브라우저 뒤로/앞으로 이동 시 해당 탭을 복원한다. 유효하지 않은 탭 값은 해당 화면 기본 탭으로 처리한다.
- 기존 요구사항·화면·프로그램·이력·산출물 경로의 기본 탭은 유지한다. 탭 링크를 만들 때 다른 쿼리 값도 보존한다.
- 좁은 화면에서는 경로를 가로로 스크롤할 수 있도록 했다.
