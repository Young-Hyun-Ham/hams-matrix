# 관리자 이력관리 검색 조건 및 상세 모달

- 작성일: 2026-11-11 (한국시간)
- 요구사항: 회원관리와 동일한 검색 조건 제공, 공통 스타일의 상세 모달 표시.

## 주요 변경사항

- 회원관리·이력관리에서 같은 검색 폼 사용: 이름·이메일 검색, 전체/프로젝트 미배정/특정 프로젝트 선택, 조건 변경 시 첫 페이지 이동.
- 이력의 검색 대상은 작업자. 이름은 당시 기록된 이름과 현재 이름, 이메일은 현재 계정 이메일로 검색한다. 프로젝트 조건은 작업자의 현재 배정 상태를 기준으로 한다. 삭제된 계정의 과거 이름 검색은 유지한다.
- master는 현재 workspace, 상품 관리자는 관리 상품의 범위로 검색하며 다른 범위의 프로젝트는 서버에서 차단한다. 목록과 전체 건수에 동일한 조건을 적용한다.
- 상세 보기는 공통 `workspace-dialog admin-detail-dialog` 스타일을 재사용한다. 변경 전/후 JSON, 작업자·작업·한국시간, 로딩·오류·재조회·닫기·Escape를 제공한다. 화면 상단에 JSON을 알림으로 출력하던 방식은 제거했다.
- Query scope·정책·상세 캐시와 기존 권한을 유지한다. 기존 미커밋 변경을 보존했다.
