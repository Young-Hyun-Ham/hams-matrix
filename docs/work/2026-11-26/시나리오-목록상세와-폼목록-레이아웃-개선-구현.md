# 시나리오 목록·상세 및 폼 목록 레이아웃 개선 구현

작성일 2026-11-26 (한국시간, Asia/Seoul)

최신 [설계 문서](../../history/2026-11-26/시나리오-목록상세와-폼목록-레이아웃-개선-설계.md)를 다시 확인하고 빌더 세 화면에 반영했다.

## 주요 변경사항과 파일

| 변경 파일 | 주요 변경사항 |
| --- | --- |
| `app/(builder)/react-flow/scenario-list/ScenarioList.tsx` | 검색 카드 바깥 상단에 10px을 추가했다. |
| `app/(builder)/react-flow/scenario-view/ScenarioView.tsx` | 상단 여백과 본문까지의 간격을 동일한 12px 기준으로 적용했다. 작은 화면에서는 상세 캔버스가 가용 폭에 맞춰 줄어든다. |

| `app/(builder)/form-builder/list/FormList.tsx`, `FormList.module.css` | 상단 헤더를 제거하고 검색 카드 내부 우측에 신규 작성을 배치했다. 네이티브 검색 컨트롤과 조회·초기화 문구를 사용하며 기존 `returnTo`를 전달한다. |
| `README.md`, `AGENTS.md`, `CLAUDE.md`, `WORK_HISTORY.md` | 화면 동작 설명과 작업 기록 링크를 추가했다. |

DB와 마이그레이션 변경 없음. 기존 API와 검색·페이지·버전 관리 계약을 사용한다.

## 검증 및 미완료 사항

- 전체 TypeScript 검사(`tsc --noEmit --incremental false`)가 통과했다. 기본 권한에서는 Node 타입 선언에 접근하지 못해 권한을 조정해 재실행했다.
- 기본 권한으로 실행한 브라우저 회귀는 Next 시작 시 `require-hook.js` 접근 거부(EPERM)로 종료됐다.
- 전체 작업 트리의 공백 검사는 기존 `PROMPT.md`와 `app/(workspace)/layout.tsx`의 후행 공백을 보고했다.
- 변경한 TSX 5개 구문과 여백·폭·폼 링크의 정적 검증이 통과했다. 변경 대상 추적 파일의 공백 검사도 통과했다.
- 권한을 조정해 전체 브라우저 회귀를 재실행했다. 목록과 편집기 초기 단계는 진행됐고, 시나리오 편집기의 기존 `.builder-emulator` 대기 단계에서 중단됐다.
- 시뮬레이터를 거치지 않는 임시 Chrome 검증은 6개 항목을 통과했다. 시나리오 목록 상단 10px, 상세 상하 12px, 버전 패널 펼침 132px·접힘 46px을 실측했다. 폼 목록은 1440px·360px에서 검색 카드 우측 정렬과 가로 넘침 여부를 확인했고, 신규 작성 진입과 `returnTo` 전달을 검증했다.
- 전체 회귀가 멈춘 지점 이후의 과거 버전 전환, 폼 편집 후 목록 복원과 시뮬레이터 연동은 이번 재현에서 검증을 완료하지 못했다. 재개 시 임시 DB에서 세 화면을 직접 열어 해당 흐름을 확인하거나 전체 회귀의 시뮬레이터 선택자를 현재 실행 패널에 맞춘다.
