# 문서 뷰어 메뉴 접기 시 본문 단독 확장

- 작성일: 2026-11-17 (한국시간)
- 요청: 메뉴를 접으면 본문만 넓어지고 목차 폭은 변하지 않아야 한다.
- 상태: 구현 및 관련 검증 완료.

## 주요 변경사항

- 메뉴 펼침 상태에서 여백·간격을 제외한 본문:목차 비율은 기존 7:3을 유지한다.
- 목차는 펼침 상태의 30% 폭으로 계산하고 메뉴를 접어 확보한 공간 전부를 본문에 배분한다.
- 셸의 메뉴 펼침 폭을 CSS 변수로 분리했다. 뷰어에서는 현재 애니메이션 여백과 페이지 배분 비율로 펼침 기준 폭을 계산하므로 메뉴 상태에 대한 별도 저장 없이 재진입·리사이즈에 대응한다. 기본 메뉴 폭과 기존 반응형 분기는 유지한다.
- 목차 없는 문서·원문 모드는 1열, 본문 최소 500px 기준의 목차 숨김, 긴 제목 말줄임, 목차 휠 스크롤과 Mermaid 기능을 유지한다.

## 변경 파일

- `styles/workspace-shell.css`: 기존 240/214/210/0px 메뉴 펼침 폭을 `--workspace-sidebar-expanded-width`로 분리. 접기 폭 64px은 유지.
- `app/(workspace)/viewer/md/MarkdownViewer.tsx`: 메뉴 펼침 기준 목차 폭 계산과 실제 여유 공간 기준 표시 판단.
- `styles/pages/viewer/md/MarkdownViewer.module.css`: 목차는 계산된 고정 폭, 본문은 남은 공간을 사용.
- `scripts/test-viewer.mjs`: 메뉴 접기 전후 목차 폭 불변·본문 176px 증가·다시 펼칠 때 복원 검증.
- `README.md`, `AGENTS.md`, `CLAUDE.md`, `WORK_HISTORY.md`, 이전 작업 기록: 현재 동작과 후속 변경 링크 반영.

- 변경 파일 ESLint 및 `pnpm typecheck` 통과.
- 합성 문서·임시 SQLite 기반 `node scripts/test-viewer.mjs --dev` 전체 통과. 1920px 화면에서 메뉴 펼침 기준 7:3, 접기 시 목차 폭 불변(2px 이내 오차)·본문 176px 증가, 다시 펼칠 때 원래 배치 복원을 확인했다.
