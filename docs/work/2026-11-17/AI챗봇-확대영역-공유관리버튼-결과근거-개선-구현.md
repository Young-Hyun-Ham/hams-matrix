# AI 챗봇 확대 영역·공유 답변 관리 버튼·결과 근거 개선 구현

- 작성일: 2026-11-17 (한국시간, Asia/Seoul)
- 기준: [최신 설계 문서](../../history/2026-11-17/AI챗봇-확대영역-공유관리버튼-결과근거-개선-설계.md)를 다시 읽고 구현했다. 별도 변경 지시가 없는 D1~D7은 문서의 권장안을 적용한다.
- 상태: 구현 및 관련 검증 완료. 기존 미커밋 변경과 설계 문서를 보존했다.

## 주요 변경사항

- 확대 또는 좌우분리 시 기존 너비에 100px를 한 번 추가한다. 확대 패널 50%+100px, 확대 팝업 최대 860px, 분리 수동 축소 패널 30%+100px·팝업 560px이다. 모바일 패널 440px·팝업 화면 여백 제한을 유지한다.
- 분리 시 대화 열의 기존 폭과 최소 입력 폭 제약을 유지하고 실제 추가분 전체를 입력 카드에 배분한다. 최초 팝업 좌표·크기 전환 보정·tooltip도 함께 반영한다.
- 공통 상단과 두 열의 배치를 명시하고 관리 버튼은 왼쪽 대화 하단, 공유 후보는 입력 카드 내부로 옮긴다. 두 열의 독립 스크롤과 기존 입력·첨부·생성 상태를 유지한다.
- 일반 대화와 결과 모달이 공통 근거 표시를 사용한다. 모달은 기본 펼침, 근거 없는 답변은 빈 목록 생략, 복사는 원문 유지다. 답변 ID로 최신 대화를 참조하고 공유 답변 재검증 중에는 모달 본문·근거를 숨긴다.

## DB 변경 여부

- 스키마·마이그레이션·API 계약·운영 DB 변경 없음. 기존 references와 서버의 공유 열람 검증 결과를 사용한다.
- 브라우저 통합 검증은 합성 계정·임시 SQLite·모의 AI·전용 Chrome 프로필을 사용한다. 외부 유료 AI 호출 없이 실행한다.

브라우저 증빙은 임시 폴더 `matrix-navigation-browser-faKgHE`, `matrix-shared-browser-OLrgDG`에 생성됐다. 분리 패널과 결과 모달 스크린샷을 직접 확인했다. 테스트의 모달 근거는 모의 생성 응답과 임시 DB 이력에 넣은 합성 references로 검증했으며 실제 프로젝트 자료를 생성하지 않았다.

빌드 정적 페이지 생성 중 `Request failed Error` 로그가 일부 있었으나 빌드는 성공했다. 해당 요청의 원인 분석은 이번 UI 범위에 포함하지 않았다. 초기 샌드박스의 패키지 읽기 제한과 빌드/타입 검사 동시 실행에 따른 생성 타입 경로 오류는 검증 실행 환경 및 순서를 조정한 뒤 해소했고 최종 검증은 통과했다.

작업 전후 해시를 비교해 이번 대상 15개 기존 파일과 신규 UI/작업 기록 2개 외의 파일 변경·삭제가 없음을 확인했다. 기존 `HISTORY.md`, 설계 문서, DB·마이그레이션·API 소스는 변경하지 않았다.

## 미완료 사항 및 검증 한계

- 요청한 구현 범위의 미완료 사항 없음. 별도 서버 데이터 계약이나 공유 답변 전용 evidence 통합은 설계 권장안에 따라 추가하지 않았다.
- 실기기·Chrome 외 브라우저·실제 200% 확대는 별도 수동 확인 대상이다. 근거 링크는 기존 동일 탭 href를 보존하고 DOM의 목적지를 확인했으며, 모든 원본 유형의 실제 링크 이동은 별도 수동 확인 대상이다.
- 공유 답변 서버 마스킹과 전용 미리보기 캐시 차단은 기존 회귀에서 확인했다. 결과 모달을 연 상태에서 발생하는 실제 권한 회수 알림의 종단 시나리오는 별도 수동 확인 대상이며, 모달은 현재 목록 데이터와 재조회 상태를 따르도록 구현했다.
